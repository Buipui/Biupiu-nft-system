# Personal Automotive R&D Asset Space

This area is reserved for non-commercial experimentation and reference material.

## Intended contents
- Original Biupiu vehicle meshes and procedural models.
- User-created body kits and component concepts.
- Experimental materials and textures.
- Test Digital Twin configurations.
- Open-source reference code with licence metadata.
- Blender procedural modelling experiments.
- Physics experiments.
- Unreal prototype assets.

## Boundary
This is not a statement that third-party game assets are free to reuse. NFS/Forza proprietary assets remain references unless independently licensed. Each imported external dependency requires a licence/provenance record.

## Workflow
Reference -> original reconstruction/inspiration -> Biupiu asset -> validation -> optional future commercial transfer review.
