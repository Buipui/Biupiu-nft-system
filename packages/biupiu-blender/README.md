# biupiu-blender

Biupiu integration package for the Blender Android engine.

## Responsibilities
1. Launch/connect to Blender.
2. Translate Biupiu Digital Twin records into Blender scene data.
3. Load approved assets/material definitions.
4. Trigger render/simulation jobs.
5. Return scene/render metadata to Biupiu Core.

## Non-responsibilities
- Do not store the canonical research record here.
- Do not duplicate Blender's core source.
- Do not embed private keys or confidential research.
