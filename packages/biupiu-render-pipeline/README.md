# Biupiu Render Pipeline

Cross-engine orchestration layer for professional visualization. It coordinates Blender, Unreal Engine 5, Twinmotion, KeyShot, Adobe/Firefly and Runway without embedding proprietary source trees.

## Flows
- PRODUCT_STILL
- DIGITAL_TWIN
- CINEMATIC_SHOWREEL
- CONCEPT_VARIATION
- RESEARCH_VISUALIZATION

Source models remain authoritative. Generative outputs are derivative showcase assets linked to source asset IDs. Provenance is required.
