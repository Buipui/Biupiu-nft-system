# Biupiu KeyShot Visualization

Licensed-KeyShot connector layer for professional product and engineering visualization.

## Pipeline
CAD/Blender -> Asset Preparation -> KeyShot -> Showcase/Showreel

Unreal Engine 5 and Twinmotion remain the interactive/cinematic environment layer.

## Render jobs
Use `render-job.schema.json` as the stable contract between the Biupiu R&D OS render queue and a local licensed KeyShot installation or a future AWS Deadline Cloud adapter.

## Safety boundary
This package does not contain KeyShot binaries, activation material, proprietary libraries, or third-party assets.

## Profiles
Automotive, marine, eVTOL/helicopter, microturbine, biocomposite, bio-adhesive/resin, textile/fibre, product hero, engineering exploded and turntable showreel.
