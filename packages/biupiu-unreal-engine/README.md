# Biupiu Unreal Engine Integration

Unreal Engine is an external licensed runtime/toolchain integrated into the Biupiu R&D OS rather than copied into this repository.

## Role
- Digital-twin runtime and visualization
- Engineering/product visualization
- Marine, automotive, eVTOL, helicopter and microturbine scenes
- Biupiu World environments
- Showcase and cinematic production
- Simulation connector host
- Twinmotion/Datasmith interchange

## Epic account / GitHub access
The Unreal Engine source repository is EULA-gated. Link the GitHub account to the Epic Games account and accept the applicable Epic license before using Epic's private Unreal Engine source repository.

This repository stores integration contracts, manifests, adapter code and documentation only. It does not redistribute Unreal Engine source.

## Twinmotion bridge
Blender / CAD / procedural assets -> Datasmith -> Twinmotion / Unreal Engine 5 -> Biupiu Digital Twin / Showcase.

## IP boundary
Do not commit Epic-licensed engine source, binaries, Marketplace assets or restricted Twinmotion content. Store only metadata, configuration, original Biupiu assets, and legally redistributable open-source components.
