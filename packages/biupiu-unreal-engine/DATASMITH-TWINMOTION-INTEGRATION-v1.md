# Biupiu Datasmith + Twinmotion Integration v1

## Canonical pipeline
Blender / CAD / procedural generator
  -> Datasmith interchange
  -> Twinmotion visualization
  -> Unreal Engine 5
  -> Biupiu Digital Twin
  -> Simulation / Showcase

## Asset contract
Imported assets should retain: Biupiu object ID, source application/version, geometry version, material references, coordinate system, scale/unit metadata, research/project association, evidence status, IP classification, import timestamp and checksum where appropriate.

## Scene families
1. Biupiu World / main campus
2. Regenerative farming environments
3. Smart-farming digital twin
4. Materials/composites laboratory
5. Microturbine laboratory
6. Marine concepts
7. Automotive concepts
8. eVTOL/helicopter concepts
9. Product-development showroom
10. Showcase/video production environments
