# Biupiu NFT System

## Project Purpose

The Biupiu NFT System is a structured digital-asset and intellectual-property framework for the Biupiu computational art and ancient-technology research portfolio.

The system is intended to connect:

- Original physical and digital artworks
- Computational geometry and generative design
- Ancient-technology research themes
- Invention and concept records
- NFT metadata and provenance
- Signed physical works and associated art-book records
- Future crowdfunding and collector-facing releases

## Portfolio Boundary

This repository is a dedicated NFT / computational-art / IP track. It is separate from the immediate Biupiu commercial DTIC funding library unless an item is explicitly approved for transfer into that business registry.

## Core Repository Structure

- `MASTER-TEMPLATE.md` — master record template for artworks, concepts and NFT releases.
- `INVENTION-REGISTER.md` — controlled register for inventions, concepts and research-linked IP records.
- `metadata/` — future NFT metadata records.
- `artworks/` — future artwork records and provenance references.
- `research/` — research notes supporting computational geometry and ancient-technology themes.
- `releases/` — future collection and crowdfunding release plans.
