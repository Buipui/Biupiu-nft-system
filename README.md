# Biupiu NFT System

## Project Purpose

The Biupiu NFT System is a structured digital-asset and intellectual-property framework for the Biupiu computational art and personal R&D research portfolio.

The system connects:

- Original physical and digital artworks
- 3D computational geometry and generative design
- 3D holography and quantitative-phase modelling
- Ancient-technology research themes
- Ancient Africa, human origins and comparative civilization research
- Invention and concept records
- NFT metadata and provenance
- Signed physical works and associated art-book records
- Future crowdfunding and collector-facing releases
- Research-linked visualisation of photonics, electrical engineering, photovoltaic systems and advanced geometry

## Portfolio Boundary

This repository is a dedicated NFT / computational-art / IP track. It is separate from the immediate Biupiu commercial DTIC funding library unless an item is explicitly approved for transfer into that business registry.

## Thunderbolts Hypothesis Research — TB

Thunderbolts Project / Thunderbolts.info is a dedicated **exploratory hypothesis stream**, separated from established research. It may be used to generate questions concerning plasma physics, electromagnetism, ancient-technology interpretations and computational geometry.

`Thunderbolts hypothesis → precise claim → established physical constraints → computational model → conventional/null control → measurable prediction → validation`

## Validation Framework

All research claims are classified as:

- Established
- Supported Research
- Plausible Model
- Unresolved
- Inconsistent
- Speculative / Inspirational

Unconventional claims require comparison against established physical constraints, conventional controls, measurable predictions and reproducible evidence.
