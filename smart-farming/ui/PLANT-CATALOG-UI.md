# Farming System OS — Plant Catalogue UI v0.1

## Catalogue screen
Search field + crop categories + recent profiles + favourites.

## Plant card
Name • scientific name • growth stage • evidence level • compatible sensors/products.

## Plant detail
Overview | Stages | Sensors | Products | Protocols | Experiments | Results.

## Add-to-farm action
1. Select plant.
2. Select cultivar if available.
3. Select zone.
4. Confirm environmental assumptions.
5. Connect compatible sensors.
6. Start growth cycle.

## Optimisation screen
Current stage → measured conditions → applicable protocols → recommendation → evidence → approval → result.

## Product link behaviour
Products are shown as compatibility references, not mandatory purchases. Compatibility must come from the versioned catalogue.
