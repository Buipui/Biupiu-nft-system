# SF-02 Premium Farming Console — Quick Start Booklet

## 1. Before powering on
- Inspect enclosure, cables and connectors.
- Confirm the selected sensors match the configured profile.
- Confirm power supply ratings.
- Keep pumps/actuators disconnected during first software commissioning.

## 2. Start the console
Power the Raspberry Pi and allow Farming System OS to load.

## 3. Create a farm
Choose Farm -> New Farm -> add zones.

## 4. Add a plant
Choose Plant/Crop -> select a profile -> select the growing environment -> confirm the profile assumptions.

## 5. Connect sensors
Add the sensor node and run the calibration workflow before relying on measurements.

## 6. Start a growth cycle
Enter planting/start date and optional cultivar information. The OS begins stage tracking and experiment logging.

## 7. Use Intelligence
Review recommendations in the Intelligence screen. During prototype operation, recommendations require human approval before physical actions.

## 8. Record outcomes
Log observations, interventions and results. Do not overwrite historical measurements; create a corrected record where necessary.

## 9. Privacy/data controls
Review the data-sharing setting before enabling network logging. The OS will clearly indicate when telemetry is being transmitted.

## 10. Maintenance
Follow calibration, cleaning, connector and enclosure inspection intervals documented for the installed hardware.
