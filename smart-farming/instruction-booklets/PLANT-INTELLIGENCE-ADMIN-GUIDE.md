# Plant Intelligence Administration Guide v0.1

## Adding a new plant
1. Create a unique Plant ID.
2. Enter common/scientific name.
3. Define stage model appropriate to that crop.
4. Define measurable variables.
5. Add compatible sensor/product mappings.
6. Add initial evidence level L0.
7. Attach references or experimental records.
8. Test the profile in the Digital Workshop.
9. Version the profile.
10. Release it to the Farming OS catalogue.

## Updating a protocol
Never overwrite historical results. Create a new protocol version, record the changed assumptions, define the affected conditions and retain rollback information.

## Quality gate
A profile may be published as a catalogue template before it has validated optimisation protocols. The UI must clearly distinguish catalogue information from experimentally validated recommendations.
