# SF-13 Biupiu World Launcher Guide

1. Open Biupiu OS.
2. Select World.
3. Choose an environment.
4. Select a facility, home, gallery or market.
5. Select an avatar.
6. Use Research, Academy, Digital Laboratory or Intelligence Hub actions from the current context.
7. Return to Biupiu OS without losing your session context.

## Asset note
External game assets are not automatically authorised for use. Every third-party asset must pass the Biupiu licence/provenance workflow before commercial distribution.
