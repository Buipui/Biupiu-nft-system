# Plant Profile & Optimisation — User Guide

1. Search for the plant/crop.
2. Review the profile evidence level and limitations.
3. Select the applicable cultivar/environment where available.
4. Connect the recommended sensors.
5. Calibrate sensors.
6. Start the growth-cycle record.
7. Review stage-specific observations.
8. Review Intelligence Hub recommendations.
9. Approve or reject proposed actions.
10. Record the measured outcome.
11. Keep successful and unsuccessful experiments.
12. Submit eligible telemetry to the Biupiu learning network according to the user's enabled data settings.

A successful result is an experiment result, not automatically a universal growing prescription.
