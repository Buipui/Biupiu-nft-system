# SF-12 — Property + Market Integration

## End-to-end journey
Environment -> Home -> Local Market -> Product -> Commerce Entitlement -> World Access -> Personal Space.

## Prototype scope
Implement non-production catalogue records for one contemporary Biupiu home, one home interior pack, one avatar style collection, one artwork listing and one campus-market special edition.

## Entitlement types
- home_access
- interior_item
- avatar_item
- artwork_access
- digital_collectible

## Rules
Commerce status is authoritative. A catalogue item does not become owned merely because it appears in the world. Entitlements are granted only after confirmed transaction state.
