# Navigable Biupiu World — UX v0.1

## First implementation
Use a lightweight 2D/2.5D map that works on Android, desktop and tablet.

## Navigation
Tap/click a facility -> enter -> pan/zoom or move avatar marker -> select interactive station -> open content panel.

## Persistent OS controls
Home | Map | Research | Lab | Courses | AI | Community | Profile

## Facility cards
Each facility displays purpose, evidence status, available lessons, experiments and required access tier.

## Future 3D layer
The same facility IDs and content metadata should be reusable in a future 3D engine. This prevents rebuilding the research/content system when the visual layer becomes immersive.
