# SF-16 Runtime Flow

World Runtime
→ Environment Loader
→ Department District
→ Vehicle Showcase Spawner
→ Vehicle Presentation
→ Department Context
→ Intelligence Hub / Digital Lab / Academy / Gallery

## Interaction
Player/avatar approaches parked vehicle
→ vehicle highlight
→ department card
→ explore specifications/research/media
→ optional enquiry/catalogue action

## Advertising principle
The vehicle itself is the visual anchor. The surrounding environment supplies context, while the interactive panel supplies verified information.

## No forced movement
Vehicles do not need to be drivable for advertising value. A parked, highly detailed vehicle can function as a persistent 3D product advertisement and research exhibit.

## Future driveability
Driveable mode remains a separate runtime capability so that advertising/showcase assets can be deployed before physics and controls are complete.
