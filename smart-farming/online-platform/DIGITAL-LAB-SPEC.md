# Biupiu Online Digital Laboratory v0.1

## Purpose
A browser/tablet-accessible laboratory where customers can explore Biupiu research, create hypotheses, run simulations and compare results without immediately requiring physical hardware.

## Experiment workflow
Search Library -> Select Research -> Create Hypothesis -> Select Variables -> Configure Simulation -> Run -> Inspect Results -> Save Experiment -> Compare -> Export/Share.

## Experiment types
- Sensor simulations
- Soil/moisture models
- Microclimate scenarios
- Plant-growth-cycle simulations
- Material-property comparison datasets
- Energy-system simulations
- Geometry/design experiments
- AI-assisted literature-to-hypothesis workflows

## Evidence labels
Simulation, observation, experimental result, replicated result and validated protocol must remain visibly distinct.

## Safety
The online laboratory is a simulation/research environment. It does not automatically imply that a simulated result will occur in physical conditions.
