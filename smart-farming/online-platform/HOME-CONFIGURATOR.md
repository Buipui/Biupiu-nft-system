# Biupiu Home Configurator v0.1

## Flow
Choose environment -> choose plot/location -> choose home type -> customise exterior -> customise interior -> add research/learning features -> preview -> view licence/entitlement -> purchase when enabled.

## Optional features
- Private research room
- Digital laboratory terminal
- Plant conservatory
- Workshop
- Gallery wall
- Archive/library
- Community meeting room
- Avatar wardrobe
- Garden/agriculture plot

## Research-linked interiors
Furniture, architecture details and decorative elements can link to the Research Library. Historical-inspired items expose context/provenance notes.
