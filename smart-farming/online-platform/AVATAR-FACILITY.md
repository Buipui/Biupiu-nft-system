# Biupiu Avatar Studio — Facility Specification

## User flow
Enter Avatar Studio -> choose base representation -> choose cultural inspiration pack -> inspect provenance -> customise -> preview -> save -> use in world.

## Presets
Historical-inspired presets can be offered for educational contexts, while fully contemporary Biupiu presets remain available.

## Provenance panel
Every historical-inspired clothing/accessory item can expose: period, geographic context, evidence status and source notes.

## Learning integration
Selecting an item can open a related Academy lesson or Research Library entry.

## Future social layer
Avatar identity is a platform profile representation only. It does not infer or declare ancestry, ethnicity, nationality or historical identity.
