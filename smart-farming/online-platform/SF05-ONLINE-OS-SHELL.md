# SF-05 — Biupiu Online OS Shell

Prototype specification v0.1

## Shell modules
Dashboard | Research Library | Digital Laboratory | Plant Intelligence | AI Assistant | Courses | Community | Account

## Access model
The shell uses subscription entitlements rather than hard-coded plan logic. Every resource declares an access level and publication status.

## Research Library
Search -> filter -> open source -> inspect evidence level -> save -> link to experiment.

## Digital Laboratory
Create experiment -> choose template -> define variables -> run simulation -> inspect results -> save report.

## AI Assistant
The assistant receives only the approved context required for the task and identifies whether an answer is based on source material, simulation, user data or inference.

## Course integration
Every course can link directly to research resources, Digital Laboratory exercises, plant profiles and assessment activities.
