# SF-09 — Biupiu Avatar & Cultural World Architecture

## Purpose
Create an optional avatar system for the future Biupiu navigable world. Avatar packs can be inspired by documented clothing, material culture, architecture and artistic conventions associated with historical civilizations.

## Cultural integrity principles
- Avatars are educational/design representations, not claims of biological appearance for every person in a civilization.
- Use documented visual sources where available.
- Separate archaeological evidence from artistic reconstruction.
- Avoid caricature, stereotypes and invented historical details presented as fact.
- Where evidence is uncertain, label the design as an interpretation.
- Provide neutral contemporary alternatives so participation does not require adopting a historical identity.

## Avatar construction system
Avatar = base body representation + face/hair options + clothing set + accessories + materials/patterns + colour palette + cultural-context metadata.

The system should allow users to mix compatible elements while showing provenance/context for historically inspired items.

## Initial cultural research packs
- Ancient Egypt / Nile Valley
- Mesopotamia: Sumer, Akkad, Babylon and Assyria
- Ancient Levant and Phoenician traditions
- Ancient Greece
- Ancient Rome
- Achaemenid/Persian world
- Indus Valley Civilisation
- Ancient China
- Ancient India
- Mesoamerican civilisations, with separate Maya, Mexica/Aztec and other documented traditions
- Andean civilisations, including Tiwanaku and Inca contexts
- Ancient Nubia/Kush
- Ancient South African and broader southern African archaeological contexts
- Ancient West African traditions where sufficient historical/archaeological evidence supports a specific design

These are starting research categories, not a claim that each category represents a single uniform culture or appearance.

## Avatar metadata
Each item should store:
- culture/civilisation tag
- approximate period
- geographic context
- item type
- source/provenance
- confidence/evidence level
- reconstruction notes
- licence/rights status
- compatible avatar slots

## Community use
Users can select an avatar for navigation, courses, collaborative experiments, seminars and community spaces. Avatar selection must not imply the user's ancestry or ethnicity.
