# Biupiu Engine Index v1.0

## Core

- `BIUPIU-ENGINE-FOUNDATION-v1.0.md` — architecture, priorities and subsystem boundaries.
- `BIUPIU-CAD-TO-RENDER-PIPELINE-v1.0.md` — engineering-source to visualization workflow.

## Priority Tracks

- Rendering and cinematic capture.
- World streaming and immersive environments.
- Asset registry and validation.
- CAD/product visualization.
- Physics and Digital Twin integration.
- Biupiu OS and AI OS interfaces.

## Initial Vertical Slice

A Biupiu World environment with a research campus, regenerative agriculture zone, product showroom, roads, terrain, vegetation, lighting, an interactive product asset, camera sequence and reproducible validation records.

## Repository Rules

- Research, third-party code and production modules remain distinguishable.
- Every imported resource requires license, dependency, security and compatibility review.
- CAD source files remain separate from optimized visual/runtime derivatives.
- AI recommendations require validation and human promotion authority.
- No gate is marked complete without evidence such as a build, test, benchmark or reviewed artifact.

## Current Status

Architecture and pipeline documents added on branch `feature/biupiu-engine-foundation-v1`.

Implementation is not yet claimed complete: runtime source, build configuration, automated tests and working visual output still need to be created and verified.
