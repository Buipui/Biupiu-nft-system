## Japan overlap
The strongest direct overlap is Feudal Japan. The existing Main Hub already defines a Feudal Japan / Tatara Workshop destination under the Metal Making World, and the East Asian environment specification already calls for Japanese historical environments and a dedicated Katana Workshop.

The new Modern Japan/Tokyo environment should therefore be treated as an expansion/new environment package, not as an assertion that it is already rendered or deployed.

## Location-development rule
AAA games provide reference points for terrain scale, vegetation density, weather, roads, settlement composition, cinematic lighting, material response, NPC/traffic density and environmental storytelling.

Biupiu then creates original models, characters, materials, maps and world systems.
