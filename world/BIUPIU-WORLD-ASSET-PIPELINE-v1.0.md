# Biupiu World Asset Pipeline v1.0

## Asset flow
Research/Design → Digital Twin ID → Master Blender Asset → Character/Environment/Product Scene → LOD derivatives → Android package → Showroom/Showreel outputs.

## Required metadata
Every production asset carries:
- biupiu_id
- version
- department
- asset_type
- evidence_state
- provenance
- licence_status
- source_refs
- Digital Twin reference
- LOD tier

## Character gate
Base rig → specialist variant → clothing/equipment → materials → animation → LOD → Android validation.

## Environment gate
Blockout → architectural/terrain detail → materials/lighting → navigation/collision → LOD → Android validation.

## Product gate
Concept geometry → Digital Twin metadata → materials/assembly → engineering visualisation → claim review → hero render → showreel shot.

## IP rule
Unpublished IP and confidential engineering data remain outside public World assets. Public-facing scenes use approved derivative representations.
