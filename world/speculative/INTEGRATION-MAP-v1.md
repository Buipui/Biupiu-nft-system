# Speculative Space Integration Map

Speculative Atlas -> Atlantis -> Mu -> future hypothesis branches -> evidence cards -> simulation controls -> results/review.

Shared infrastructure:
- Trust/provenance records source references and model versions.
- R&D routes speculative questions into the digital laboratory.
- Virtual credits are used for experiments; simulated BPU is not a real asset.
- Every speculative site receives a persistent SPECULATIVE badge.
- Evidence cards appear before exploration.
- Reconstructed structures are marked as reconstructed.
- Alternative hypotheses never overwrite source records.
