# Biupiu World — Speculative Space

A dedicated research/simulation area for ideas that are historically disputed, mythological, weakly evidenced, or not presently established by archaeology/science.

## Rules
- Speculative claims are never promoted to historical fact.
- Every asset carries evidence class, confidence, source trail, reconstruction flag and assumptions.
- Primary/archaeological evidence is separated from literary traditions and modern hypotheses.
- Simulation explores what-if scenarios; it does not manufacture evidence.
- Competing hypotheses remain separate.
- User-developed concepts remain labelled hypotheses/designs unless independently supported.

## Current Speculative Atlas
- Atlantis
- Mu
- Previously developed Biupiu speculative civilisation/technology concepts represented in the repository's speculative index.

## Pipeline
Source -> Evidence Classification -> Hypothesis -> Scenario Model -> Simulation -> Results -> Review

No simulation result changes historical evidence classification.
