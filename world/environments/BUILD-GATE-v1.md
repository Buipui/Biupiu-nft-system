# Build Gate — Civilisation Sandbox

## Acceptance criteria
- All six current environments resolve to manifests.
- Each has an avatar gate and library.
- Generated assets inherit evidence/reconstruction metadata.
- Atlantis and Mu remain speculative.
- Mod packages cannot silently alter evidence records.
- Virtual barter/economy remains separate from real BPU settlement.
- Mobile and desktop quality tiers are supported.
- Procedural generation is deterministic through a recorded seed.

## Prototype target
Load one environment, spawn an avatar, show evidence/orientation, permit movement, open a spatial library object, and enter one farming interaction.

This repository currently contains the architecture/specification rather than a deployed 3D client.
