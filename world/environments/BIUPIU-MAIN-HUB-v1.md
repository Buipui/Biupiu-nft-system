# Biupiu World Main Hub — Campus Prototype

The Main Hub is the shared arrival campus for subscriber avatars. It is a neutral orientation space rather than a civilisation environment.

## Spatial flow
Avatar Arrival -> Welcome Plaza -> Civilisation Library -> Destination Gates

## Gate A — FARMING WORLD
Dedicated gateway into regenerative agriculture and historical farming environments.

Destinations:
- Inka Mountain Farming
- Maya Lowland Farming
- Babylonian Irrigation Farming
- future farming environments

Core systems: terrain, crops, water, soil, harvesting, storage, barter and regenerative experiments.

## Gate B — METAL MAKING WORLD
Dedicated gateway into metallurgy and materials environments.

Destinations:
- Feudal Japan / Tatara Workshop
- India / Wootz Workshop
- Damascus / Crucible-Steel Workshop
- Biupiu Modern Materials Lab

Core systems: materials library, historical metallurgy, comparative metallurgy, virtual microscopy, pattern/microstructure observation, materials simulations and learning videos.

## Shared hub services
- Avatar profile
- Civilisation library index
- Video library
- Education progress
- Trust/provenance
- Mod/sandbox manager
- World travel map
- Virtual-only inventory and learning records

## Visual design
A premium Biupiu research campus: contemporary, restrained and technology-forward. The two gates clearly communicate their disciplines, while civilisation-specific architecture begins after entering a destination.
