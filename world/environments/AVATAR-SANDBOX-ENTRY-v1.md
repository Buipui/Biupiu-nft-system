# Biupiu World Avatar Sandbox Entry

## Entry sequence

1. Subscriber selects a civilisation/environment.
2. System displays civilisation badge and evidence status.
3. Avatar enters an orientation zone.
4. Online library becomes available as spatial objects.
5. Avatar chooses Explore, Learn, Farm, Barter or Research.
6. The environment loads only the required model/interaction package.
7. Actions produce simulation events and learning records.
8. Results can be compared across civilisation worlds.

## Sandbox spaces

Each environment contains:
- Gate / spawn zone
- Library
- Social plaza or equivalent gathering area
- Agriculture zone
- Water/engineering zone
- Marketplace/barter zone
- Research/observation zone

## Avatar model
The same subscriber avatar can travel between worlds, while clothing, accessories, tools and local environmental props can change according to the selected world. Cosmetic adaptation must not imply historical identity claims.

## Technical boundary
This specification defines the sandbox architecture. A future client can implement it using a game/3D engine, web client or mobile/desktop application.
