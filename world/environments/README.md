# Biupiu World — Civilisation Environment Library

This layer defines the online environment/library architecture for civilisation worlds and avatar entry.

Each civilisation receives:
- a dedicated environment package;
- an online knowledge/library portal;
- architectural and environmental model specifications;
- avatar spawn/entry rules;
- evidence cards and learning objects;
- farming, barter and exploration links.

The repository stores specifications and source metadata. It does not claim that 3D assets are already rendered or deployed.

## Environment pipeline

Civilisation Index -> Evidence Library -> Environment Manifest -> Model Library -> Avatar Entry -> Simulation -> Provenance
