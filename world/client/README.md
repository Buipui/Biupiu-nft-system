# Biupiu World Main Hub Client

The client is the executable prototype layer for the Main Hub architecture.

## Development gate
1. Install Node.js (LTS recommended).
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local Vite URL.

## Current gate result
- Scene bootstrap: implemented.
- Procedural plaza: implemented.
- Farming gate: implemented.
- Metal Making gate: implemented.
- Avatar spawn placeholder: represented by the central hub marker.
- Real destination loading: not yet implemented.
- Authentication/authorization: not implemented; repository gate policy remains authoritative.
- Production deployment: not claimed.
