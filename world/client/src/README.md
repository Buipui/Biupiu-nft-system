# Main Hub client prototype

This is the first executable scene layer for the Biupiu World Main Hub.

## Scope
- Deterministic, lightweight procedural welcome plaza.
- Two destination gate structures: Farming World and Metal Making World.
- Orbit camera for desktop/mobile pointer interaction.
- No external 3D assets are bundled yet.
- Route metadata remains aligned with `BIUPIU-MAIN-HUB-SCENE-v1.json`.

## Status
Prototype scaffold only. This commit does not represent a deployed application, production authorization, or finished art assets.
