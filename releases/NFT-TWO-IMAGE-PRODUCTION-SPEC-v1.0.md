# BIUPIU NFT TWO-IMAGE PRODUCTION SPEC v1.0

## Standard for all future releases

### Image 01 — PROVENANCE

**Filename pattern:** `[RELEASE]-01-PROVENANCE-vX.Y`  
**Role:** research lineage + collector presentation.

Composition:
1. BIUPIU brand lock-up using the approved emblem and colour system.
2. NFT/release title.
3. Research ID(s).
4. Evidence classification.
5. Short plain-language research basis.
6. Computational geometry method / algorithm ID.
7. Artwork preview or integrated hero artwork.
8. Provenance information that is already verified.
9. Clear indication of prototype/reconstruction/hypothesis status where applicable.

### Image 02 — STANDALONE NFT

**Filename pattern:** `[RELEASE]-02-STANDALONE-vX.Y`  
**Role:** independent collectible artwork.

Composition:
1. Research-derived computational geometry as the hero.
2. BIUPIU palette and visual DNA.
3. Subtle BIUPIU emblem/wordmark where appropriate.
4. No unnecessary technical panels.
5. No generated fake metadata.
6. No unsupported historical claims.
7. Composition must remain complete without Image 01.

## Relationship between the two

The images share:
- the same release ID;
- research linkage;
- computational concept;
- approved brand system;
- generation/version lineage.

They do **not** share an asset hash. Each image receives its own final SHA-256 hash.

## Computational authenticity

Where a release is designated computational art, the generation record must preserve the algorithm, version, input/data status, parameters and random seed. If AI-assisted visual generation is used, the production record must separately identify the AI-assisted stage and distinguish it from deterministic computational generation.

## Research integrity

Documented archaeology, reconstructed modelling, experiments, hypotheses and speculative concepts must remain distinguishable. Artwork can be inspired by a hypothesis, but it must not turn the hypothesis into an asserted historical fact.

## IP gate

Before public release, verify that all external images, datasets, fonts, source code and reference material are either owned, licensed, public-domain/appropriately reusable, or excluded. Protect confidential Biupiu IP and do not expose patent-sensitive implementation details unnecessarily.

## Current paused state

The image-generation stage is intentionally paused. Repository architecture and release indexing continue without creating or claiming final images.
