# Forza-adjacent Open Source Research Layer v1.0

Searches identified public projects useful for concepts rather than proprietary Forza game code.

## Useful references
- Forza Engineering Assistant: vehicle data types and engineering-oriented calculations.
- JDS physicsEngine: open physics implementation with suspension/vehicle concepts and a documented Forza-level simulation target.
- Blender-Car-Streamliner: Blender tooling for car modelling, rigging, custom parts and Unreal export.
- Open-source vehicle audio projects: RPM/load-driven engine, transmission, exhaust and intake audio architecture.

## Integration rule
Only code whose licence permits the intended use may be incorporated. Forza game assets, extracted proprietary databases and copyrighted content are not treated as Biupiu assets.

## Modernisation targets
1. Data-driven tuning schema.
2. Parameter validation and units.
3. Separate visual/performance state.
4. Suspension and tyre simulation adapter.
5. Aero parameterisation.
6. RPM/load audio hooks.
7. Blender-to-Unreal asset pipeline.
8. Deterministic build/revision records.

## Status
References indexed for technical study. Implementation is being rewritten around Biupiu interfaces rather than copied wholesale.
