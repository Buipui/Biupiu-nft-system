# Biupiu Invention & Concept Register v0.2

**Purpose:** Controlled index for Biupiu inventions, technical concepts, computational-art systems and research-linked IP associated with the NFT / art portfolio.

## Registration Rules

1. Assign a unique immutable record ID before public release.
2. Record the earliest known creation date and revision.
3. Separate documented facts from hypotheses and future concepts.
4. Link each NFT/artwork to its underlying concept where applicable.
5. Preserve supporting calculations, source references, sketches, source code and computational outputs.
6. An NFT mint does not itself establish patentability or legal IP protection.
7. Potentially protectable inventions should be reviewed with qualified IP counsel before public disclosure.
8. Keep the NFT/art portfolio separate from the immediate commercial DTIC library unless explicitly transferred.
