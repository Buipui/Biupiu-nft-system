# Biupiu Showcase Render Adaptation — Online Model Asset Plan v1.0

## Purpose
Adapt legally usable third-party 3D models into Biupiu showcase prototypes for the Blade Micro-Turbine programme and its Marine, eVTOL and Helicopter/Aerospace configurations.

## Asset-selection rule
Third-party models are treated as **base geometry/reference assets**, not Biupiu-owned IP. Licence terms must be recorded before redistribution or commercial packaging. Biupiu-original propulsion modules, turbine internals, blade geometry, materials, interfaces and engineering claims remain separate design layers.

## Render families

### BL-01 — Biupiu Blade Micro-Turbine
- Standalone turbine product render.
- Hero 3/4 view.
- Exploded view: intake → compressor → combustor/thermal core → turbine → exhaust → generator/drive interface.
- Blade/composite material callouts.
- Engineering concept status clearly marked.

### MR-01 — Marine
- Biupiu turbine module integrated into a futuristic marine propulsion pod.
- Vessel-side and underwater/propulsion views.
- Emphasis on modularity, cooling, intake/exhaust routing and maintainability.
- No performance claims until validated by simulation/testing.

### EV-01 — eVTOL
- Use an open/logo-free eVTOL base where licence permits.
- Replace the propulsion architecture visually with Biupiu micro-turbine modules.
- Create distributed-propulsion and hybrid-electric concept variants.
- Label as concept/CAD visualization, not flight-certified hardware.

### HC-01 — Helicopter
- Use the CC0 generic turbine helicopter as the preferred base where suitable.
- Develop roof/side/rear propulsion-module variants.
- Create conventional rotorcraft and hybrid-electric concept layouts.
- Keep turbine performance assumptions separate from the visual model.

### AX-01 — Aerospace
- Adapt the aircraft base into a Biupiu propulsion demonstrator.
- Produce nacelle/pod integration views.
- Maintain a separate validation layer for aerodynamics, thermal loads, structural loads and propulsion sizing.

## Asset provenance
Every imported model must have:
- source URL
- creator
- original licence
- download/access date
- permitted uses
- attribution requirement
- modification status
- Biupiu-original additions
- redistribution status

## Important boundary
These renders are **design visualisations**. They do not establish that a turbine configuration is aerodynamically, thermally, structurally, acoustically or propulsion-system viable. Those questions remain in the Biupiu simulation/experimental validation pipeline.
