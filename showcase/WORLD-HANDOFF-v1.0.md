# Biupiu World Handoff v1.0

Gate 10 is the controlled bridge from reviewed hero assets into downstream Biupiu World systems.

Downstream targets:
- Biupiu World
- Showreel pipeline
- Digital Twin catalog

A handoff is generated only when a human review record explicitly contains APPROVE and all four checks PASS. Otherwise the handoff remains HOLD.

No asset is copied into a release package merely because a render exists.
