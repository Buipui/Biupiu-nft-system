# Biupiu Unreal Showcase Pipeline

Blender/approved source assets → provenance check → UE5 asset import → materials/lighting → cinematic or interactive showcase.

Initial render families:
- BL-01 Biupiu Blade Micro-Turbine
- MR-01 Marine
- EV-01 eVTOL
- HC-01 Helicopter
- AX-01 Aerospace

Third-party models remain base/reference assets unless their licences permit the intended use. Biupiu-original propulsion, materials and engineering layers remain separately identified.
