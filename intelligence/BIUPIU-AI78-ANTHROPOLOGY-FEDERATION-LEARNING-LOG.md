# AI-78 Anthropology Federation Learning Log
Date: 2026-09-21

## Harvest finding
The earliest anthropology-specific retrieval architecture located in authoritative historical documentation is the Yale Institute of Human Relations Cross-Cultural Survey, begun in 1935. HRAF later formalized the approach around original text, systematic subject classification, human indexing and culture-level organization.

## Learning events
1. Observation: anthropology retrieval historically depended on structured human classification before computer search.
Lesson: semantic retrieval should retain explicit subject/category metadata rather than relying exclusively on keyword similarity.

2. Observation: HRAF indexed at paragraph level and preserved original source material.
Lesson: retrieval units must remain linked to their source context and should be independently inspectable.

3. Observation: culture-level organization enables cross-cultural comparison.
Lesson: Biupiu federation should support entity/group dimensions in addition to free-text search.

4. Observation: modern semantic search can improve discovery but can also obscure provenance.
Lesson: semantic relevance must never replace source identity, context or evidence classification.
