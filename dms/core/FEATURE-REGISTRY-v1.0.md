# Feature Registry v1.0

Stable feature IDs are the contract between products, department modules and the entitlement engine.

Examples:

- `agri.operations`
- `agri.analytics.basic`
- `hemp.traceability`
- `hemp.processing`
- `manufacturing.production`
- `manufacturing.advanced-analytics`
- `inventory.operations`
- `quality.release`
- `maintenance.management`
- `rnd.experiment-management`
- `engineering.simulation`
- `ai.forecasting`
- `robotics.orchestration`
- `digital-twin.advanced`
- `dms.multi-site`
- `customer.rnd-participation`

Each feature must declare product compatibility, safety classification, required role and subscription plans before production activation.
