# Biupiu World — Private-to-World Promotion Gate

No automatic promotion.

P0 OWNERSHIP — Owner explicitly identifies the model/system for review.

P1 TECHNICAL VALIDATION — reproducible inputs; deterministic/versioned model; unit and numerical sanity checks; benchmark comparison where available; physical calibration where applicable; limitations recorded.

P2 IP AND LICENCE — rights reviewed; third-party licences compatible; confidential information removed from customer package; patent-sensitive material reviewed before disclosure.

P3 PRODUCTISATION — customer interface defined; failure boundaries documented; telemetry/privacy boundaries defined; security review completed.

P4 OWNER DECISION — PROMOTE_TO_WORLD, RETAIN_PRIVATE, or REVISE_AND_RETEST.

Customer-facing Biupiu World must never infer approval from technical validation alone.
