# After Effects Adapter

## Target

After Effects is the Biupiu compositing, motion-graphics and VFX layer.

## Planned Biupiu commands

- create/open project
- create composition from a registered asset set
- place digital-twin annotations
- apply controlled motion-graphics templates
- queue render
- export deliverable
- return output hash and provenance record

Legacy Adobe CEP/ExtendScript samples are compatibility references only. Keep legacy calls behind an adapter boundary so the R&D OS remains application-neutral.

## Validation gate

No live execution is claimed until a local After Effects installation and adapter test harness are available.
