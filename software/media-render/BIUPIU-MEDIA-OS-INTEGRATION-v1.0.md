# Biupiu Media OS Integration v1.0

**Date:** 18 September 2026

The professional visualization package is now registered as a first-class R&D OS subsystem.

## Cross-links

- Blade/microturbine engineering projects -> professional render and animation jobs
- Unreal Engine 5 -> interactive digital-twin layer
- KeyShot -> precision product visualization
- Blender -> master 3D asset layer
- Twinmotion -> rapid environment and walkthrough layer
- Runway / Firefly -> AI-assisted media layer
- Premiere Pro / After Effects -> finishing layer

## Operating rule

The R&D OS stores the relationship between engineering source, authoritative asset, media job and final media artifact. Visual media cannot automatically elevate a hypothesis, simulation or design concept to validated engineering evidence.
