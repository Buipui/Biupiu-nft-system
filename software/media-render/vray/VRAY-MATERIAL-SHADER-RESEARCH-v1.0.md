# V-Ray Material & Shader Research v1.0

## VRayMtl GLSL
The verified Chaos GLSL reference is useful as a research baseline for:
- diffuse
- reflection/refraction
- metalness
- anisotropy
- sheen
- coat
- thin-film effects
- Fresnel calculations
- environment sampling

It is especially useful for viewport approximations and material-preview experiments.

## alSurface reference
The MIT-licensed Chaos alSurface repository provides reference implementations involving BRDFs and subsurface-scattering/dipole techniques.

### Biupiu material research targets
- Hemp fibre composites
- Hemp/resin laminates
- Bio-adhesive surfaces
- Textile weave appearance
- Bio-based coatings
- Ceramic/crystal surfaces

Material appearance remains visualization evidence, not measured optical/mechanical material data.
