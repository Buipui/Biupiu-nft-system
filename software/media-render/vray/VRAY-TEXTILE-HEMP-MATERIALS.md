# V-Ray Textile & Hemp Materials Research

## Research bridge
Use physically based shader references to build visual hypotheses for Biupiu materials.

### Material classes
- Woven hemp textile
- Hemp fibre composite
- Hemp/resin laminate
- Bio-adhesive coating
- Natural-fibre surface
- Bio-based protective coating

### Workflow
Material measurement/data → parameterized shader → V-Ray render → compare against reference samples → record deviations → update material model.

ThunderLoom is indexed as an external research reference for woven cloth. It is not copied here without confirming its source-license requirements.
