# v0.5 API Security — Integration Step

Implemented in this step:

- controlled development organisation/user bootstrap
- short-lived development session creation
- token hashing verification
- package script: npm run dev:session
- development-session automated test

Important boundary:

The session bootstrap is a development/testing mechanism only. It does not replace production identity management, passwordless authentication, SSO, MFA, secret rotation or secure session storage.

Next integration target:

1. Wire api-gate.js into server.js.
2. Require authentication on protected routes.
3. Filter collection reads by authenticated organisation.
4. Enforce tenant ownership on writes and transitions.
5. Audit authentication failures and permission failures.
6. Add end-to-end HTTP tests.
7. Run CI and, separately, PostgreSQL integration tests when a real database is available.
