# Biupiu R&D OS v0.2 — Engineering Execution Roadmap

## Objective
Advance the v0.1 runnable MVP toward a multi-user research operating system while preserving the repository's evidence-aware research doctrine.

## v0.2 engineering sequence
1. PostgreSQL-ready relational model for projects, research objects, sources, claims, hypotheses, experiments, datasets, results, failures, IP records and audit events.
2. Authentication and organisation/tenant boundary design.
3. Explicit relationships between research objects and lifecycle stages.
4. Evidence engine with ESTABLISHED, SUPPORTED, PRELIMINARY, HYPOTHESIS, SPECULATIVE, CONTRADICTED and INCONCLUSIVE states.
5. R0–R9 maturity workflow and gate validation.
6. Experiment → measurement → validation → replication workflow.
7. Knowledge-graph API and visual graph layer.
8. Repository synchronisation interface for research documents and machine-readable records.
9. Import/export of JSON research packages.
10. Automated test coverage for lifecycle and evidence rules.

## Non-production status
v0.1 is a development MVP. It is not a production SaaS, regulated laboratory information system, security-certified platform or validated scientific instrument. Production deployment requires security review, database hardening, access controls, backup/recovery, privacy controls, observability and independent workflow validation.

## Commercial validation gate
Before licensing claims are made, test the software with real research workflows and record usability, reliability, workflow completion, customer discovery and willingness-to-pay evidence.

## Target architecture
`WEB UI → API → DOMAIN SERVICES → POSTGRESQL / OBJECT STORAGE → SEARCH / KNOWLEDGE GRAPH → AI & SIMULATION CONNECTORS`
