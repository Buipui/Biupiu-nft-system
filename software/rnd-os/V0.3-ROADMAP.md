# Biupiu R&D OS v0.3 Roadmap

## Gate sequence

1. **Security boundary** — completed: role, tenant and authentication primitives.
2. **Runtime sessions** — migration defined: PostgreSQL session persistence with hashed tokens and expiry.
3. **Tenant-aware API** — next: resolve authenticated organisation and enforce scope on every mutable/read collection.
4. **PostgreSQL adapter** — next: runtime connection, migration runner and repository interfaces.
5. **Relationship integrity** — validate source/target existence, relation types and tenant ownership.
6. **Audit enforcement** — state changes, authentication events, exports/imports and permission failures.
7. **Verification** — unit, API, PostgreSQL integration and tenant-isolation tests.

## Current status

The repository now contains the v0.3 security boundary and PostgreSQL migration design. JSON remains the development datastore. PostgreSQL is not yet connected at runtime.

## Production gate

Production deployment requires successful automated tests, security review, tenant-isolation verification, backups/recovery, secrets management, rate limiting, observability and dependency review.

No production-security certification or regulated-laboratory validation is implied by this roadmap.
