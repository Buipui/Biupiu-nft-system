# Gate 6 — Main Campus Dynamic Department Navigation

The Main Hub consumes subscriber entitlements to construct navigation.

PUBLIC users see the hub and public information. Department gates are visible but protected. An authorised department is ENTERABLE; an unauthorised department is LOCKED. Locked navigation never exposes protected resource data. Tier alone never unlocks a department. Suspended/pending accounts receive no protected department entry. The UI is presentation only; server/API authorization remains authoritative.

Destinations: Farming World (SMART_FARMING), Metal Making World (SMART_METAL_WORKSHOP). Future departments use the same destination model.
