# Biupiu R&D OS — v0.5 Gate

## Objective

Move tenant and role controls to the API boundary and establish a consistent security-audit path.

## Implemented

- API route policy engine
- authentication/authorisation integration point
- viewer-level read policy
- researcher-level mutation policy
- tenant-record assertion helper
- security-event audit helper
- automated API route policy tests

## Security model

Public:
- /api/health
- /api/meta

Authenticated:
- all other API routes

Role policy:
- GET: viewer minimum
- POST/mutations: researcher minimum

Tenant policy:
- organisation scope must come from the authenticated principal
- records outside that organisation must be rejected

## Verification boundary

The API gate modules are implemented and unit-tested. The existing legacy server routes still require integration with the gate before the entire runtime can be considered enforced.
