# Biupiu Smart Systems

Common UI and integration layer for future connected Biupiu systems.

Smart Farming is the reference architecture. Domain systems consume the common registry, gate, digital-twin, telemetry, command and audit concepts through adapters.

Initial targets:
- Smart Farming
- Digital Workshop / Virtual Garage
- Marine
- Aerospace
- Smart Metallurgy / manufacturing
- Research and laboratory systems

The layer is intentionally open and modular during prototype development. Physical validation can later establish the requirements for proprietary control, optimisation and analytics modules.
