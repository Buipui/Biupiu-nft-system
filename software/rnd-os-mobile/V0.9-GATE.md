# Biupiu R&D OS Mobile — v0.9 Authentication Gate

## Objective

Add a development session boundary so the Android application can represent an authenticated R&D OS user without moving authorisation into the client.

## Implemented

- Session domain model.
- Session-store abstraction.
- Development-only in-memory session store.
- Authentication state model.
- Development-session ViewModel boundary.
- Explicit production storage boundary.

## Security rule

The Android client does not decide organisation access or role permissions. The R&D OS server remains authoritative.

## Production requirement

A production implementation must use Android Keystore-backed secure storage, token expiry/revocation, secure transport, session renewal and a reviewed identity flow.
