# Biupiu R&D OS Mobile — v0.8 API Integration Gate

## Objective
Connect the Android client to the existing R&D OS API through an explicit network boundary without bypassing server-side authentication or tenant controls.

## Implemented foundation
- API base URL configuration.
- Kotlin API client abstraction.
- Health and dashboard endpoint boundaries.
- Bearer-token request boundary.
- Explicit API error model.
- No direct database access from Android.

## Security boundary
The Android client must not supply or trust organisation scope as an authorisation mechanism. The server remains authoritative for identity, role and tenant isolation.

Production authentication, secure token storage, TLS configuration and account recovery remain separate security gates.

## Acceptance criteria
- App can call `/api/health`.
- App can call `/api/dashboard` with a development bearer token.
- HTTP failures are surfaced as typed API errors.
- Dashboard data is mapped into the mobile domain model.
- No PostgreSQL credentials or server secrets are embedded in the app.

## Boundary
This gate does not claim production authentication, production TLS hardening, Google Play readiness or regulatory compliance.
