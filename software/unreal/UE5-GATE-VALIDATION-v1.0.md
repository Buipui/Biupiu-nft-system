# Biupiu UE5 Gate Validation v1.0

## Gate A — Repository integrity
- [x] UE5 project scaffold exists.
- [x] Runtime C++ module exists.
- [x] Game and Editor targets exist.
- [x] Modeling Tools, Interchange and Editor Scripting are enabled.
- [x] Movie Render Pipeline is enabled.
- [x] Unreal generated/build directories are excluded from Git.

## Gate B — Workstation integration
Requires the user's Windows workstation:
- [ ] Unreal Engine 5.x installed.
- [ ] Visual Studio 2022 17.7+ installed.
- [ ] Game development with C++ workload installed.
- [ ] Visual Studio Tools for Unreal Engine installed.
- [ ] UE project opens successfully.
- [ ] Visual Studio solution generation succeeds.
- [ ] BiupiuAssetStudioEditor builds as Development Editor.

## Gate C — First asset
- [ ] Import a test mesh.
- [ ] Apply a PBR material.
- [ ] Place the asset in a level.
- [ ] Validate scale, normals, UVs and collision.
- [ ] Save the asset under /Game/Biupiu/Assets.

## Gate D — Cinematic/showreel
- [ ] Create a Level Sequence.
- [ ] Enable/use Movie Render Queue.
- [ ] Create an MRQ or Movie Render Graph preset.
- [ ] Render a short test sequence.
- [ ] Verify output frames/video and log warnings.

## Gate E — Biupiu cross-discipline test
Use one representative asset from automotive, marine, eVTOL/helicopter, microturbine, advanced materials and regenerative-agriculture digital twin tracks.

Repository/workflow gates can be prepared here; workstation-dependent checks require UE5 and Visual Studio on the user's machine.
