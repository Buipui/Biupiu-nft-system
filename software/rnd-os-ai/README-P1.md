# Biupiu P1 Native AI Runtime

Run from this directory with the project environment:

    python -m pytest -q

P1 verification covers evidence gating, irreversible-action approval,
bounded continual adaptation, repository path confinement and deterministic
algorithm commitments.

Passing these tests verifies the first-party control plane only; it does not
constitute proof of production model accuracy, hardware acceleration, or
blockchain deployment.
