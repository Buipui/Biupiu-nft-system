# Biupiu Windows Blender Pipeline v1.0

Windows production flow:

Biupiu R&D OS → Asset Registry → Digital Twin → Biupiu World package → Official Blender Windows → scene assembly → materials/lighting → animation → render → visual/rights/claims review → showreel/editorial package

## Character production
Use the Gate 02 shared humanoid base and Gate 03 specialist variants. Build department-specific clothing, tools and animation as modular attachments so one rig can serve Windows and Android.

Initial specialist packages: Farming; Metallurgy; Textiles; Materials.

## Environment production
Build Main Hub, department districts, research facilities and civilisation environments as independent Blender scene collections. Preserve evidence-state metadata for historical reconstructions and clearly separate speculative environments.

## Product-development production
Product scenes bind to Digital Twin IDs and claim classes. Target families include Biupiu Blade microturbines, Marine/AQUA concepts, AeroBlade GT, eVTOL, helicopter/aerospace concepts, advanced materials/composites, robotics/photonics systems and regenerative-agriculture equipment.

## Showreel
The Blender scene library feeds 16:9 master, 30-second trailer, 15-second teaser, 9:16 vertical, 4:5 campaign, World showroom loops and department stills. Every shot inherits provenance and claim metadata.
