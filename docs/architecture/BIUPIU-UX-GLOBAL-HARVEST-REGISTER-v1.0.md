# Biupiu UX Global Harvest Register v1.0

## Sources and patterns
- Android/AAOS: glanceability, consistent terminology, large touch targets, clear active/inactive states.
- Ferrari: tactile, driver-oriented HMI, configurable modes and physical/digital control continuity.
- Ferrari Tailor Made: curated materials, collections and bespoke specification.
- Pagani: real-time configuration, deep personalisation, photorealistic presentation and saved/shareable configurations.
- CyanogenMod/LineageOS: device abstraction, configurable Android platform and community-driven adaptation as historical architecture reference.
- KMP/Compose Multiplatform: shared domain/UI strategy with native escape hatches.

## Global language rule
Search and harvest English, German, Italian, French, Spanish, Portuguese, Chinese, Japanese, Korean and Russian sources. Translate concepts into a common evidence record; do not treat language as evidence quality.

## Selection criteria
A UX or software pattern enters Biupiu architecture only after:
SOURCE -> LICENCE -> TECHNICAL RELEVANCE -> ACCESSIBILITY -> SECURITY -> IMPLEMENTABILITY -> TESTABILITY -> PROVENANCE

## UX principles promoted
- glanceable information
- predictable navigation
- contextual controls
- progressive disclosure
- live visual feedback
- high-quality visualisation
- persistent configuration summary
- reversible actions
- explicit state
- premium restraint

## Non-copying rule
Biupiu may learn from public architecture and documented interaction principles but does not reproduce proprietary Ferrari/Pagani UI, branding, artwork, code or assets.
