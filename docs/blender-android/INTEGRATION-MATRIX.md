| Capability | Mobile Lite | Mobile Full | Remote |
|---|---|---|---|
| 3D asset inspection | Yes | Yes | Yes |
| Parametric/model editing | Yes | Yes | Yes |
| EEVEE rendering | Yes | Yes | Yes |
| Cycles | No/limited | Target | Yes |
| Heavy simulation | Limited | Device-dependent | Yes |
| Large Biupiu World scenes | Limited | Device-dependent | Yes |
| AI-driven scene generation | Bridge | Bridge | Bridge |
| Digital Twin visualization | Yes | Yes | Yes |
| High-resolution final render | Limited | Device-dependent | Yes |

## Gate rule
A feature is exposed in the Android UI only after the selected deployment tier passes the corresponding build/runtime test.
