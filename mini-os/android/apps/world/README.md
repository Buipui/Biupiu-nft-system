# Biupiu World Android Foundation

SF-40 creates the first real Android source scaffold.

Target:
- Kotlin
- Jetpack Compose
- Android application ID: com.biupiu.world
- shared Biupiu World/showcase contracts

The first build is intentionally minimal. Showcase manifest ingestion and navigation are subsequent integration steps.

The repository must not claim an APK is verified until CI or a local Gradle build produces and verifies the artifact.
