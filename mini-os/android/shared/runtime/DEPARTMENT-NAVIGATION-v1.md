# Biupiu Department Navigation v1

Gate 17 connects the entitlement-aware Main Hub UI to the native department module registry.

1. Main Hub resolves subscriber entitlement.
2. Locked modules remain disabled.
3. Authorized modules resolve through the shared Gate 16 module contract.
4. The platform opens the corresponding native department screen.

The current preview account is PUBLIC with no department entitlements, so Farming and Metal Workshop remain locked while R&D OS is enterable. This is a preview configuration, not a production authorization decision.
