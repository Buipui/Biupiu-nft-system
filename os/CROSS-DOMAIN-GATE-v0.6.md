# Biupiu OS Cross-Domain Integration Gate v0.6

Integrated two existing repository models through OS adapters:
1. cycle-physics screening;
2. integrated propulsion mission/mass screening.

The original models remain in `simulators/` and are not copied into the OS layer.

The OS now provides a common execution, evidence and audit boundary across both.

This is a software integration demonstration. The models remain research/screening models and are not physically validated or certified by this gate.
