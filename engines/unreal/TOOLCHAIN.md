# UE5 Toolchain

## Windows development
Primary UE development target: Windows workstation. Configure Epic Games Launcher or an approved source build, Visual Studio/C++ toolchain, and required platform SDKs.

## Android
Android is a packaged runtime target for selected Biupiu experiences. Keep Android UI/control functions in the existing Android application layer and use packaged UE experiences where appropriate.

## Asset pipeline
Blender/approved modelling tools → asset validation/provenance → Unreal import → Biupiu UE asset library → project-specific packaging.

## Licensing
Record source URL, creator, licence, access date, permitted use, attribution and modification status for every third-party model or asset before redistribution/commercial packaging.
