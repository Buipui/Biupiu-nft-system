# Biupiu Unreal Engine 5 Integration

## Purpose
This layer integrates Unreal Engine 5 as Biupiu's high-performance 3D visualization, digital-twin, simulation-visualization and showcase runtime.

## Boundary
The Unreal Engine source tree is NOT vendored into this repository. Biupiu-owned Unreal projects, plugins, configuration, schemas and integration code live here and use an externally installed/source-available UE5 toolchain subject to Epic's Unreal Engine EULA and applicable third-party licences.

## Planned projects
- BiupiuWorld — interactive environments and sites.
- BiupiuDigitalTwin — digital-twin visualization.
- BiupiuShowcase — cinematic/product presentation.
- BiupiuSimulation — visualization of validated simulation outputs.

## Planned plugin modules
BiupiuCore, BiupiuData, BiupiuDigitalTwin, BiupiuResearch, BiupiuSimulation, BiupiuMaterials, BiupiuPropulsion, BiupiuVehicles, BiupiuMarine, BiupiuAerospace, BiupiuAgriculture, BiupiuWorld and BiupiuShowcase.

## Source-of-truth rule
Research records, experiment data and digital-twin schemas remain authoritative. Unreal visualizations do not by themselves establish scientific, structural, aerodynamic, thermal or propulsion validation.
