# UE5 Local Validation Gate v1.0

1. Install Unreal Engine 5.6 through Epic Games Launcher.
2. Generate/open the project from `BiupiuDigitalTwin.uproject`.
3. Confirm `BiupiuDigitalTwin` and `BiupiuSimulation` plugins load without errors.
4. Open `/Game/Biupiu/Maps/DT_Bootstrap` after the bootstrap content is created locally.
5. Run the BL-01 fixture and inspect twin/provenance/telemetry output.
6. Package a development build only after editor validation passes.

## Evidence to record
- Engine version
- Platform
- Plugin load result
- Build/compile result
- Runtime result
- Packaging result
- Any warnings/errors

No successful local validation is claimed by this repository change.
