# UE5 Project Contract v1.0

Each UE5 project must document:

1. Exact Unreal Engine version.
2. Target platform(s).
3. Plugin dependencies.
4. Canonical Biupiu schema/data inputs.
5. Asset provenance references.
6. Simulation datasets and source commit.
7. Build configuration.
8. Packaging/signing status.

A project is not considered production-ready merely because an editor scene renders successfully.
