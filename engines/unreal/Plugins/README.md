# Biupiu UE5 Plugin Foundation

Planned plugin boundaries:

- BiupiuCore — lifecycle, configuration and shared runtime services
- BiupiuData — schemas, serialization and API contracts
- BiupiuDigitalTwin — digital-twin actor/component mapping
- BiupiuResearch — research/evidence presentation
- BiupiuSimulation — simulator-result visualization
- BiupiuMaterials — material and biomaterial metadata/visualization
- BiupiuPropulsion — propulsion and blade micro-turbine visualization
- BiupiuVehicles — shared vehicle systems
- BiupiuMarine — marine integration
- BiupiuAerospace — eVTOL/helicopter/aerospace integration
- BiupiuAgriculture — regenerative farming digital twins
- BiupiuWorld — environment/world services
- BiupiuShowcase — cinematic presentation and product visualization
