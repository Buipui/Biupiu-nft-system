# BiupiuData — Schema Adapter v1.0

Maps canonical Biupiu digital-twin records into UE-facing contracts.

## Contract
- Schema ID
- Schema version
- Entity ID
- Source dataset/reference
- Provenance ID
- Timestamp
- Units
- Coordinate/reference frame where applicable
- Validation status

The adapter is read/validation oriented. It does not silently mutate canonical research data.
