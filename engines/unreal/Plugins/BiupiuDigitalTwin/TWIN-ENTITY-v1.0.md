# TwinEntity v1.0

## Actor identity
Every UE digital-twin actor should expose:
- EntityId
- EntityType
- SchemaVersion
- ProvenanceId
- SourceReference
- ValidationStatus

## Components
- TwinMetadataComponent
- ProvenanceComponent
- TelemetryComponent
- SimulationResultComponent

## Rule
A visual actor is a representation of a canonical entity, not the canonical entity itself.
