# Official Blender Windows Engine

## Upstream
- Official mirror: https://github.com/blender/blender
- Official Windows downloads: https://www.blender.org/download/
- Official download mirror: https://download.blender.org/

## Biupiu role
This is the desktop Windows engine path for Biupiu R&D OS. It is the primary high-performance authoring/rendering target for Biupiu World characters, environments, product-development prototypes and showreels.

Android remains a separate optional engine using the reviewed Blender Android fork.

## Policy
Pin an explicit Blender release/commit for production scenes. Do not silently track the main development branch. Use Blender Python automation for repeatable scene assembly, asset metadata, LOD generation and render setup.
