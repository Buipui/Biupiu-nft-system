## E. BLOCKED / DEPENDENCY-BOUND
- Live CI closure when workflow runs or commit-status checks are absent.
- Live host/device validation when the required Windows/UE5/Android environment is not connected or execution permission is unavailable.
- Production deployment/security closure pending identity provider, managed database, secure key management, TLS, rate limiting and independent testing.
- Physical validation pending calibrated equipment, raw data, provenance, repeatability and safety review.
- Vehicle runtime simulation and physical validation pending an appropriate connected engineering environment, validated models, test equipment and specialist safety review.

## F. SUPERSEDED / OBSOLETE HANDLING
Superseded records must remain in history with a pointer to the replacement. No deletion is performed solely because a task is old, duplicated or unfinished.

## Closure rule
A gate is not closed merely because a document, scaffold, adapter or code path exists. Closure requires the applicable implementation, integration, validation, indexing/provenance and repository persistence evidence.
