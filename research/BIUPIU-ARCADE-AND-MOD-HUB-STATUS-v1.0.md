# Biupiu Arcade & Mod Hub Status v1.0

Date: 21 September 2026

## Registered

The following architecture has been integrated into the Biupiu R&D repository:

- Rights-aware virtual arcade architecture
- Emulator/platform adapter model
- Native Biupiu Arcade Runtime target
- Machine-readable game/resource registry
- Rights classification: GREEN / BLUE / YELLOW / ORANGE / RED / GREY
- Free Unreal + Unity + future Biupiu Engine Mod Hub architecture
- Creator identity, provenance, licence and dependency model
- Security/compatibility/rollback gates
- Digital museum / retro-PC / console-room concept
- Native conversion path from external compatibility resources to Biupiu-owned infrastructure

## Important boundary

No third-party game, ROM, emulator or asset has been marked commercially cleared by this integration.

Publisher bankruptcy, closure, abandonware status, archive availability or age are not treated as proof of redistribution rights.

## Native development priority

1. Build the Biupiu resource registry.
2. Build the Biupiu Arcade Runtime Interface.
3. Build a native cabinet/session prototype in Unreal.
4. Build the creator/mod metadata pipeline.
5. Add rights/provenance validation.
6. Add Unity adapter.
7. Add Biupiu-native game/module format.
8. Add sandboxing, signed manifests and rollback.
9. Introduce only individually verified external content.
10. Replace dependency on external runtimes progressively with Biupiu Engine capabilities where technically and legally appropriate.
