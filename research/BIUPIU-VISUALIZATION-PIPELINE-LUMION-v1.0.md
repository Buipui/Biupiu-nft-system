# BIUPIU VISUALIZATION PIPELINE — LUMION INTEGRATION v1.0

**Status:** Executed as architecture/index integration
**Date:** 18 September 2026
**Track:** CG-3D / DIGITAL-TWIN / CODEX / NFT-IP
**Scope:** Lumion-compatible visualization workflow; no proprietary Lumion binaries/assets are redistributed.

## Purpose
Lumion is indexed as a real-time architectural/product visualization and presentation layer, not as the engineering solver or canonical research database.
Biupiu's engineering truth remains in the R&D OS, Digital Twin, CAD/CAE, simulation and experimental records. Lumion can consume approved geometry/material outputs for rapid visualisation, environment studies, design reviews and cinematic presentation.

## Pipeline
Research Object → CAD/Blender/Unreal/approved geometry → PBR/material package → Lumion visualization → review/render/video → provenance record

Engineering validation path:
Research → Model → CFD/FEA/physics → Digital Twin → physical test

These paths are linked but not conflated.

## Primary use cases
- Biupiu marine concepts: hulls, hydrofoils, propulsors and turbine concepts.
- Automotive concepts: body geometry, composites, aero surfaces and product presentation.
- eVTOL/helicopter concepts: approved visual geometry and environment studies.
- Biupiu Blade & Micro-Turbines: blade/component presentation after engineering models are versioned.
- Regenerative agriculture: farms, water systems, facilities and landscape concepts.
- Advanced manufacturing: factory layouts, robotics cells and machinery visualisation.
- Biupiu World / computational-art environments: evidence-separated visual world building.
- Investor/government presentation imagery and video.

## Interoperability
Preferred interchange is based on documented, licensed workflows and standard geometry/material formats rather than copying proprietary application files into the repository.
Potential interchange formats to evaluate per project: FBX, OBJ, DAE/COLLADA, SKP, DWG/DXF, 3DS and MAX.
The exact supported format and feature set must be checked against the target Lumion release before production use.

## LiveSync layer
Where a supported CAD/BIM connector is available, LiveSync is treated as an optional rapid-iteration bridge between the authoring application and Lumion.
Repository rule: record source application/version, connector/plugin version, geometry/material export settings; retain the authoritative source model outside the Lumion presentation layer; never treat a rendered image as proof of engineering performance.

## PBR/material workflow
Biupiu material research can produce controlled PBR packages for hemp/natural-fibre composites, bio-adhesives/resins, metals and hybrid materials, coatings, ceramics, textiles and regenerative landscape materials.
Material provenance must link back to the Material Genome and Digital Twin records. Literature values remain evidence inputs, not certified design allowables.

## Digital Twin connection
Lumion is assigned the visualisation node in the Digital Twin architecture:
Physical System ↔ Sensor/Data Layer ↔ Digital Twin Model ↔ Engineering Simulation ↔ Visualisation
Lumion may display approved states/variants, but it does not become the authoritative source for sensor measurements, CFD/FEA results, material allowables, experimental conclusions, safety certification or IP ownership.

## Unreal Engine 5 relationship
Unreal Engine 5 remains the interactive/simulation/real-time environment track. Lumion is a complementary rapid architectural/product visualization path.
- Lumion: fast presentation, architectural/environmental visualisation and client/investor imagery.
- Unreal Engine 5: interactive digital twins, simulation interfaces, immersive environments and advanced real-time systems.
- Blender/CAD/CAE: authoring, geometry, modelling and engineering preparation.
- V-Ray: physically based/high-fidelity rendering where that workflow is required.
No application is treated as a replacement for the others.

## GitHub resource policy
Only resources with a clear licence/permission and useful technical provenance should enter the Biupiu resource registry.
Do not import or link as approved resources: cracks/unlocks/keygens, pirated proprietary software, redistributed proprietary Lumion binaries, unlicensed commercial asset packs, or assets whose licence cannot be established.
Community repositories are discovery leads until licence and provenance are verified.
