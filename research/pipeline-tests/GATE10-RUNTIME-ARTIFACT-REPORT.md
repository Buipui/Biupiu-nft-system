# Gate 10 Runtime Artifact Report Contract

**Schema:** 1.0  
**Status:** INTAKE FORMAT IMPLEMENTED — NO RUNTIME PASS CLAIMED

A real runtime artifact report must record provenance and explicit comparison results.

Required fields:
- `schemaVersion`
- `provenance.application`
- `provenance.version`
- `provenance.generatedAt`
- `sourceArtifact`
- `comparison.expectedContract`
- `comparison.status` — PASS or FAIL
- `comparison.errors` — array
- `environment` — optional runtime/toolchain details

A PASS is valid only when the artifact was actually generated by the stated runtime/exporter and the comparator returned zero errors. Templates and repository fixtures cannot be used as runtime evidence.
