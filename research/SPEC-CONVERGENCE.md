# BIUPIU Speculative Source Convergence & Genealogy Registry

**Version:** 1.0  
**Date:** 15 September 2026  
**Status:** Active

## Purpose

Track apparent convergence between Vibes of Cosmos, Robert Sepehr / Atlantean Gardens, Divergent Libertalia and other alternative-history sources without treating repeated claims as independent corroboration.

## Source-genealogy rule

`Creator ≠ source ≠ original evidence.`

For each claim, identify the earliest traceable source, then map later reinterpretations. A claim repeated by multiple channels counts as independent convergence only when the channels can be shown to have arrived at it independently.

## Evidence categories

- A — Directly demonstrated
- B — Strongly supported
- C — Plausible/incomplete
- D — Testable hypothesis
- E — Unsupported/contradicted
- M — Mythological/cultural

## Convergence scoring

The Hypothesis Convergence Index (HCI) should consider:

1. source independence;
2. primary-source proximity;
3. geographic specificity;
4. chronological specificity;
5. physical testability;
6. independent supporting evidence;
7. contradictory evidence;
8. reproducibility.

Popularity, number of YouTube videos, or number of social-media reposts are not evidence multipliers.

## Output

Each convergence record should ultimately produce a claim graph, evidence table, geographic layer and CODEX test record. Negative results are retained as first-class research outputs.
