# AI Experimental Protocol v1.0

## Objective
Provide a repeatable method for testing AI-generated research hypotheses.

1. Record the source/claim.
2. Define a falsifiable hypothesis.
3. Identify independent/dependent variables and controls.
4. Select simulation and/or physical test.
5. Record assumptions before execution.
6. Run the test without changing the success criterion after seeing results.
7. Store raw data and analysis.
8. Record supported, unsupported or inconclusive outcome.
9. Record limitations and next test.
10. Link the result back to the originating research object.

AI-generated hypotheses are proposals, not evidence.
