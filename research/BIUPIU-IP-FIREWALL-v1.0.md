# Biupiu IP Firewall v1.0

## Information-control states
`PUBLIC → INTERNAL → CONFIDENTIAL → PRE-PATENT → PATENT FILED → TRADE SECRET`

## Pre-publication gate
Flag potentially novel technical disclosures for prior-art, FTO and IP review before public release.

## Rule
Repository novelty is not a patentability determination. Public disclosure, prior art, ownership, inventorship and applicable jurisdiction must be reviewed separately.
