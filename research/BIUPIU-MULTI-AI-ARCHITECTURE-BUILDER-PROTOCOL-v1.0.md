# Biupiu Multi-AI Architecture Builder Protocol v1.0
Execution gate: AI-NATIVE-01
Scope: Native Biupiu OS + Biupiu AI

## Mandatory evidence chain
1. Repository harvest record
2. Authority and dependency map
3. Specialist challenge record
4. Implementation diff
5. Deterministic test result
6. CI or host evidence when available
7. Failure and regression record
8. Promotion and index update

## Housekeeping
Canonical files stay in their owning subsystem. Existing contracts are reused where compatible. Failed and superseded evidence is preserved. Implemented, host-tested, regression-pass and verified remain separate states. Indexes and matrices are updated whenever a gate changes state. External code remains reference-only until licence, security and compatibility review. Secrets never enter the repository. Interrupted work remains queued.

## Gate promotion
REGISTERED -> IMPLEMENTED -> HOST_TESTED -> REGRESSION_PASS -> VERIFIED

Source implementation alone cannot produce VERIFIED.
