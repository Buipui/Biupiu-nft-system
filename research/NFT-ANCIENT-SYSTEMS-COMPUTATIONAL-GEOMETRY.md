## Purpose

Connect Biupiu ancient-technology, archaeology, anthropology and historical-engineering research with computational geometry and generative artwork for the founding NFT crowdfunding project.

NFTs are an **output/provenance layer**, not an evidence layer. An artwork may represent established archaeology, a reconstruction, an engineering model, an unresolved hypothesis or speculative inspiration, but its metadata must say which one.

## Core evidence-layer network

All relevant NFT research must use the master architecture in `research/BIUPIU-EVIDENCE-LAYER-ARCHITECTURE.md`.

Core source layers:

1. **Primary archaeology/history** — sites, artefacts, stratigraphy, inscriptions, dating and primary records.
2. **JSTOR (`SRC-JSTOR`)** — scholarly archaeology, anthropology, history, material culture, technology and environmental research.
3. **AnthroSource (`SRC-ANTHROSOURCE`)** — anthropology, archaeology, craft production, technology transmission and human-material systems.
4. **ResearchGate/scientific literature (`SRC-RESEARCHGATE`)** — archaeometry, metallurgy, materials, genetics, experimental archaeology, engineering and computational research; publisher/DOI versions preferred.
5. **Emerald Insight (`SRC-EMERALD`)** — sustainability, water, agriculture, infrastructure, engineering management and systems/implementation research.
6. **Robert Sepehr / YouTube / Atlantean Gardens (`SRC-SEP`)** — alternative-history and ancient-civilisation hypothesis generation only; never primary proof.
7. **Ancient texts (`SRC-TEXTS`)** — historical testimony and cultural traditions, carefully separated from mythology and later interpretation.
8. **Scientific primary data (`SRC-SCI`)** — dating, genetics, isotopes, geology, palaeoclimate, chemistry and physics.
9. **Patents/prior art (`SRC-IP`)** — modern implementation and FTO context.
10. **Public/declassified technical archives (`SRC-DECLASS`)** — historical engineering source material, used only when lawfully public/declassified.
11. **GitHub / BIUPIU CODEX (`SRC-GITHUB-CODEX`)** — reproducible algorithms, code, datasets and simulation methods with licence/provenance controls.
12. **Computational validation (`SRC-COMPUTE`)** — GIS/CAD/CFD/FEA/EM/thermal/acoustic/network/optimisation/digital-twin modelling.
13. **Physical validation (`SRC-EXPERIMENT`)** — reconstruction, prototypes, measurements and repeatability.

## NFT research-to-art pipeline

`Source → exact claim → source genealogy → evidence classification → historical/technical interpretation → model/reconstruction → computational geometry → algorithm → simulation/validation → original artwork → NFT metadata → provenance record`

A source is never silently converted into a factual NFT claim.

## Source genealogy and independence

Every research-backed artwork should retain:

- source ID(s)
- exact article/book/video title
- author/creator
- publication/video date
- URL or stable identifier
- page number or video timestamp where relevant
- original cited source lineage
- independent corroborating sources
- evidence status
- Biupiu research/departments IDs
- computational model/version
- artwork algorithm/version
- generation seed where applicable
- source-code status
- software/dependency versions
- asset/metadata hashes
- licence/provenance status
- IP review status.

Repeated YouTube videos or websites that derive from the same original source do **not** count as independent corroboration.

## Evidence labels

- **A — Directly demonstrated**
- **B — Strongly supported**
- **C — Plausible/incomplete**
- **D — Testable hypothesis**
- **E — Unsupported/contradicted**
- **M — Mythological/cultural**
- **S — Speculative/inspirational**

Legacy NFT labels DOCUMENTED / RECONSTRUCTED / EXPERIMENTAL / HYPOTHESIS / SPECULATIVE remain valid presentation labels, but the master A–E/M/S evidence control should be stored internally.

Artwork inspired by an unresolved Sepehr hypothesis must use wording such as **“speculative interpretation,” “research hypothesis,” or “artistic reconstruction”**, not “proven ancient technology.”

## Artwork disclosure classes

### Class A — Evidence-backed
Artwork represents well-established archaeological/scientific evidence.

### Class B — Reconstruction
Artwork reconstructs a documented site, artefact, technology or landscape; reconstruction assumptions are disclosed.

### Class C — Experimental engineering
Artwork represents a Biupiu computational/physical reconstruction being tested.

### Class D — Research hypothesis
Artwork visualises a specific, falsifiable hypothesis.

### Class E — Speculative inspiration
Artwork is inspired by mythology, alternative-history narratives or unresolved ideas and is explicitly labelled as such.

## IP and licensing controls

Public source material is not automatically free of rights. Third-party images, code, maps, datasets, papers, video frames and research outputs must be licence-checked.

Potentially patentable Biupiu inventions and confidential technical material must remain separated from public NFT artwork repositories until IP review is complete.

NFT artwork should preferentially use original Biupiu-generated geometry, models, renderings and writing, with external sources retained as properly attributed research references rather than copied artwork.

## Research-to-NFT separation rule

The NFT system may **visualise research**, but the NFT itself does not establish the truth of the research.

`Research evidence ≠ artwork ≠ proof`

This rule is mandatory for ancient-civilisation, alternative-history, archaeological and engineering-hypothesis collections.
