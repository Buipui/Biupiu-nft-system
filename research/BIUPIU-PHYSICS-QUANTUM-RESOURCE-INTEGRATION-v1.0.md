## Government/declassified research lane

Use NARA declassified records and agency FOIA/declassification collections as historical evidence sources. Declassified status is not evidence of technical validity, current capability or current government policy. Preserve provenance, date, classification/declassification status and evidentiary role.

## Engineering routing

PHYSICS -> MATH -> PHYS-SYS -> COMPUTE -> DIGITAL-TWIN -> AERO / AUTO / MARINE / ROBOTICS / ENERGY / MATERIALS -> TEST-SIM -> VALIDATION

QUANTUM -> PHOTONICS / MATERIALS / ENERGY / COMPUTE -> HYBRID-SIM -> DIGITAL-TWIN

Classical solvers remain the engineering baseline unless a domain-specific validation gate establishes otherwise.

## Licence/provenance rule

Third-party code is never copied into Biupiu merely because it was discovered. Store source URL, repository identity, observed licence, version/commit, dependency constraints, security notes and intended integration mode. Reuse requires licence compatibility, security review, API compatibility and regression evidence.
