## Integration decision
These resources are added to the intelligence/resource radar and gate-learning matrix as external references. They are **not automatically imported**.

Before code reuse: inspect repository licence, dependency graph, security posture, maintenance state, API compatibility and Biupiu interface contract. Then run isolated tests before promotion.

## New architecture opportunities
- observability events feed the gate-learning schema;
- evaluation results become regression evidence;
- memory systems remain subordinate to provenance and authoritative state;
- Digital Twin simulation can become a regression target;
- knowledge-graph/RAG relations feed dependency-impact analysis.

## Boundary
No claim is made that these projects are production-ready for Biupiu or that their current upstream state has been fully audited. The audit records candidate resources for subsequent gates.
