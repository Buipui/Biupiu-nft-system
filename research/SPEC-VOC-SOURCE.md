## Evidence-control rule

VOC claims are not upgraded to established facts because they appear repeatedly across VOC, Sepehr/Atlantean Gardens, Divergent or other channels. Repetition is not independent corroboration. Source genealogy must be established before a convergence claim is counted.

## Test protocol

**Claim → original video/map → exact proposition → coordinates/geometry → source genealogy → authoritative baseline → null hypothesis → computational test → uncertainty → result → evidence status.**
