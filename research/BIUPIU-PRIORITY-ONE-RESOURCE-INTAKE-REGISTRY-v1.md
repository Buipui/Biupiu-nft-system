# Biupiu P1 Resource Intake Registry

## Intake
DISCOVERED -> LICENSE_CHECK -> SECURITY_CHECK -> COMPATIBILITY_CHECK -> TEST -> REGISTER -> PROMOTE

## AI/ML candidates
OpenClaw, Hermes Agent, n8n, TensorFlow, Ollama, LangGraph, CrewAI, DSPy, vLLM,
Flower, PySyft, Qiskit ML and PennyLane remain candidate integrations until each
specific version passes Biupiu provenance, licence, security, compatibility and regression gates.

## Foreign-language sources
Gitee / GitCode; Japanese and Korean institutional engineering repositories; German/EU
institutional repositories; original-language project documentation. Preserve source URL,
commit/version, licence and original-language metadata. Translation is an indexing aid only.

## OEM/system-data intake
ACCEPT: OEM-published SDK/API/documentation; manufacturer sample code/firmware explicitly
licensed for reuse; public standards/diagnostic specifications; vendor developer downloads
with explicit rights; compatible open-source OEM-adjacent tooling.
REJECT: leaked/proprietary dumps; credentialed dealer/service images; DRM/access-controlled
extraction; copied binaries with unclear redistribution rights.

## Mod/upload intake
Import metadata and licence evidence first. Do not copy third-party assets into production
without explicit rights. Generate original Biupiu equivalents where rights are absent.
