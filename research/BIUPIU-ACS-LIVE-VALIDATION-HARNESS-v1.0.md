# Biupiu ACS Live Validation Harness v1.0

**Date:** 19 September 2026  
**Purpose:** next execution gate for the Assassin's Creed Shadows rendering-reference track.

## Gate ACS-07 — Live-validation harness

This gate converts the ACS rendering research into a deterministic test contract for a connected Windows/Unreal Engine/rendering host. It does not claim live measurements until that host is available.

### Test scene

Use one original Biupiu Japan World scene containing:
- terrain + foliage
- original architecture/props
- water/wet surfaces
- fog/volumetrics
- day/night lighting
- controlled camera path

### Render modes

A. UE5 baseline/Lumen  
B. UE5 hardware RT where supported  
C. RT/path-tracing research mode where supported  
D. approved alternative renderer adapter

### Required measurements

For each mode record:
- engine/renderer version
- GPU/CPU
- resolution
- frame time and FPS
- VRAM/system memory
- scene and asset-manifest IDs
- renderer settings
- output hash
- licence/provenance state
- visual-quality observations

### Acceptance

A live result is valid only when generated by the connected host and accompanied by machine-readable provenance. Missing hardware/runtime measurements remain PENDING, never inferred.

### Rights boundary

Only original Biupiu assets and appropriately licensed/open-source dependencies may enter the scene. Assassin's Creed/Ubisoft assets remain reference-only.
