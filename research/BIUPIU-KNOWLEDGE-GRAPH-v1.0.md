# Biupiu Knowledge Graph v1.0

## Canonical graph
`SOURCE → CLAIM → CONCEPT → MATERIAL → ALGORITHM → MODEL → EXPERIMENT → DATA → RESULT → REPLICATION → PROTOTYPE → IP → PRODUCT`

## Cross-links
The graph may also connect organisations, researchers, standards, patents, datasets, equipment, safety constraints, funding routes and commercial applications where properly sourced.

## Principle
Every important relationship should be traceable back to its source or explicit Biupiu inference. Unsupported relationships remain hypotheses.
