# Biupiu Automotive Bio-Composite Body-Panel Coupon & Attachment Matrix v1.0

**Purpose:** define the next physical-validation gate for removable/non-crash-critical vehicle panels.

## Test families

| ID | Test | Variables | Primary outputs |
|---|---|---|---|
| CP-01 | Material conditioning | dry / humidity / thermal exposure | mass change, thickness change, retained properties |
| CP-02 | Tensile | fibre/resin/layup | E, strength, strain-to-failure |
| CP-03 | Flexural | same | flexural modulus/strength |
| CP-04 | Interlaminar | same | ILSS / failure mode |
| CP-05 | Impact | low-velocity impact | absorbed energy, damage area, residual strength |
| CP-06 | Adhesive/fastener attachment | adhesive, insert, fastener, edge distance | joint stiffness, peak load, failure mode |
| CP-07 | Vibration/damping | frequency and temperature | modal response, damping trend |
| CP-08 | Thermal cycling | controlled temperature cycles | dimensional change, cracking, joint integrity |
| CP-09 | Moisture cycling | humidity/water conditioning | retained strength and bond integrity |
| CP-10 | Vehicle-panel trial | removable body/service panel on OEM running gear | fit, mass, NVH observations, durability observations |

## Material/control matrix

- M1 flax / bio-epoxy
- M2 hemp / bio-epoxy
- M3 flax-hemp hybrid / bio-epoxy
- M4 flax / furan or PFA system
- M5 flax or hemp / EVO-derived epoxy
- C1 glass / epoxy control
- C2 carbon / epoxy control

No material property is to be populated from an assumed value when measured or traceable literature data are available.

## Panel attachment rules

Initial vehicle trials use removable panels only. OEM-qualified steering, braking, suspension, hubs, shafts, crash structures and powertrain mounts remain unchanged.

Attachment coupons must record:
- adhesive system and surface preparation
- fastener/insert type
- thickness and edge distance
- cure/post-cure
- joint geometry
- environmental conditioning
- failure location and mode

## Promotion gates

1. Coupon repeatability established.
2. Environmental retention quantified.
3. Attachment failure mode understood.
4. Panel mass/CG impact documented.
5. Vehicle fit and serviceability confirmed.
6. Controlled vehicle test completed without safety-critical architecture changes.
