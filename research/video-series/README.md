# Biupiu Original Engineering Video Production

This directory contains original Biupiu engineering-video production records.

## Operating rule

Videos are developed from the Biupiu research model:

`Source → Claim → Evidence → CODEX/AAT/ALA/GEO → IP/Prior Art → Model → Prototype → Measurement → Review → Publication`

Original Biupiu material should be prioritised: narration, diagrams, CAD, simulations clearly labelled as simulations, prototype footage, measurement data, captions and source notes.

## Current production records

- `EP01-PRODUCTION-PACKAGE-v1.0.md` — Episode 01 script architecture, scene plan, rights controls and publication gate.

## Status vocabulary

- `PLANNED` — concept only.
- `PRE-PRODUCTION` — script, storyboard and source/rights review.
- `FILMED` — original footage recorded and archived.
- `EDITED` — edit completed.
- `REVIEWED` — technical and rights review completed.
- `PUBLISHED` — final public release link recorded.

No episode should be marked filmed, tested or published without the corresponding artifact and evidence record.
