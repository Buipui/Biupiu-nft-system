# Biupiu Aerospace — Digital Twin MSFS Integration v1.0

FS2002 and MSFS 2024 simulator research is now routed through the Aerospace Digital Twin into Aerospace Design, CG-3D, Avionics, CODEX, AI, Robotics, Materials, Manufacturing, HMI, Simulation, Testing and Biupiu World.

## Integration flow

source → provenance/licence → simulator/version classification → extraction/analysis → Digital Twin object → department cross-links → simulation → validation → approved design record

## Aerospace routing

- Aircraft geometry → Aerospace Design → CG-3D, Materials, Manufacturing
- Flight dynamics → Aerospace/Simulation → AI, CODEX, Digital Twin
- Avionics → Aerospace/Avionics → Robotics, Embedded, HMI
- SimConnect telemetry → CODEX → Digital Twin, AI, Testing
- EFB/cockpit → HMI → Avionics, Robotics, CG-3D
- Textures/liveries → CG-3D → Showreel, Biupiu World
- Scenery/world data → Digital Twin → Aerospace, Biupiu World
- Legacy BGL research → CODEX → Digital Twin, Preservation
- AI pilot research → AI → Aerospace, Simulation
- Plant-composite research → Advanced Materials → Aerospace, Manufacturing
- Simulation test cases → Testing → Aerospace, AI, Robotics

## Controls

Every imported reference retains source, creator, licence/permission state, simulator/version, tool version, provenance, transformation history and validation state where applicable. Simulator assets are not treated as real-world aerospace certification evidence. Proprietary assets remain excluded unless permission permits use.
