# Biupiu Technology Readiness & Evidence Engine v1.0

## Evidence states
`ESTABLISHED → SUPPORTED → PRELIMINARY → HYPOTHESIS → SPECULATIVE → INCONCLUSIVE → CONTRADICTED`

## Research maturity
`R0 IDEA → R1 SOURCE → R2 HYPOTHESIS → R3 MODEL → R4 BENCH TEST → R5 PROTOTYPE → R6 REPLICATION → R7 ENGINEERING DEMONSTRATOR → R8 COMMERCIAL FEASIBILITY → R9 PRODUCT/TECHNOLOGY`

## Rule
Evidence state and maturity may only advance when the relevant evidence, measurement, replication, safety, engineering or commercial gate has been satisfied. Simulation is not physical proof; a prototype is not automatically a validated product.
