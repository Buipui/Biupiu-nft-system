# BIUPIU ANTHROSOURCE / ANCIENT TECHNOLOGY REGISTER

**Version:** 1.1  
**Date:** 19 September 2026  
**Status:** Active — anthropology/archaeology evidence layer

## Purpose

AnthroSource is a permanent Biupiu evidence source for Ancient Applied Technology, archaeology, anthropology, craft production, human-material relationships, cultural ecology, technology transmission and ancient agricultural landscapes. Use it to establish historical/anthropological context and generate testable research questions; do not treat it as automatic proof of engineering performance.

ResearchGate is the scientific/engineering discovery layer used alongside publisher, DOI and institutional records. Emerald remains the systems/implementation layer. Patents/public declassified records address modern implementation and prior art. GitHub/CODEX converts validated questions into reproducible computational tests.

## Next-gate methodology

Ancient-technology computational reconstruction:
archaeological object/site → high-resolution documentation → digitisation/vectorisation → parametric geometry → competing hypotheses → null/alternative models → simulation/statistics → experimental reconstruction → independent replication → evidence status → IP/NFT gate.

Landscape archaeology:
archival imagery/LiDAR/DEM → georeferencing → 3D/GIS reconstruction → GeoAI candidate detection → archaeological verification → temporal/environmental cross-check → CODEX provenance.

Anthropological interpretation:
material/process → human skill/labour → social/ecological context → comparative evidence → engineering question → independent scientific test.

## Source-control rule

Every record must capture exact title, author, year, DOI/stable URL, relevant pages/section where available, proposition used, source lineage, department codes, evidence status and whether a primary archaeological/scientific source should be preferred.

ResearchGate records are discovery/repository records; final evidence should preferentially cite the publisher, DOI, institutional repository or primary dataset when available. Multiple ResearchGate uploads of the same work are one source lineage.
