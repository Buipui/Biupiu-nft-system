# BIUPIU Core Evidence-Layer Architecture

**Version:** 2.0  
**Date:** 15 September 2026  
**Status:** Active — master source and evidence-control architecture

## Purpose

This file defines the permanent Biupiu evidence architecture for Ancient Applied Technology (AAT), anthropology, archaeology, ancient civilizations, historical engineering, materials, water systems, agriculture, human origins and computational reconstruction.

The architecture separates **hypothesis generation**, **scholarly evidence**, **primary evidence**, **scientific validation**, **engineering reconstruction**, **computation** and **Biupiu experimentation**. No source category automatically proves a claim.

## Core evidence layers

### L01 — Primary archaeological and historical evidence
Excavated sites, artefacts, stratigraphy, inscriptions, dated materials, museum records, primary historical documents and original datasets.

### L02 — JSTOR
Scholarly research for archaeology, anthropology, history, material culture, technology, environment and related humanities/social-science literature.

### L03 — AnthroSource / American Anthropological Association
Anthropology, archaeology, human-material relationships, craft production, technology transmission, cultural ecology and social organisation. Initial records are maintained in `research/ANTHROSOURCE-ANCIENT-TECHNOLOGY-REGISTER.md`.

### L04 — ResearchGate / scientific literature discovery
Experimental science, archaeometry, metallurgy, materials science, genetics, engineering, computational research and author-uploaded papers. Prefer DOI/publisher/institutional versions for final evidence.

### L05 — Emerald Insight / Emerald Publishing
Engineering management, sustainability, water systems, agriculture, infrastructure, optimisation, implementation and socioeconomic/system-level analysis. Identify exact publication/DOI before assigning independent-evidence status.

### L06 — Controlled alternative/speculative sources
Robert Sepehr, YouTube, Atlantean Gardens, Divergent, VOC and other hypothesis-generation material. Exact claims must be decomposed, source genealogy traced and independently tested.

### L07 — Ancient texts and historical literature
Primary or near-primary textual testimony, translations, chronicles, technical descriptions and mythological/cultural traditions. Preserve original/translation provenance and distinguish cultural narrative from historical evidence.

### L08 — Scientific databases and primary research
Archaeogenomics, radiocarbon/dating, isotopes, palaeoclimate, geology, geophysics, chemistry, physics and environmental science.

### L09 — Patents / prior art / IP
Existing modern implementations, claims, drawings, materials, algorithms and freedom-to-operate context. Record jurisdiction, priority, legal status and relevant claims.

### L10 — Public and declassified technical archives
Historical engineering, turbine, materials and systems documentation that is lawfully public/declassified. No classified/restricted information is incorporated.

### L11 — GitHub / BIUPIU CODEX
Reproducible code, algorithms, simulation methods, datasets, notebooks, computational archaeology, geometry reconstruction and engineering models. Record repository, commit/version, author, licence, dependencies and provenance.

### L12 — Biupiu computational validation
GIS, CAD, CFD, FEA/FEM, multiphysics, thermal, EM, acoustic, network, statistical, optimisation and digital-twin tests.

### L13 — Biupiu physical/experimental validation
Laboratory reconstruction, materials testing, hydraulic experiments, prototypes, sensor measurements and repeatability studies.

## Permanent source-routing rule

`hypothesis/source → exact claim → source genealogy → PRIMARY → JSTOR → ANTHROSOURCE → RESEARCHGATE → EMERALD → TEXTS/SCIENCE → patents/declassified → GIS/CODEX → experiment → evidence status → IP/NFT gate`

Not every investigation requires every layer; skipped layers must be justified in the research record.

## Evidence status

- **A — Directly demonstrated**
- **B — Strongly supported**
- **C — Plausible/incomplete**
- **D — Testable hypothesis**
- **E — Unsupported/contradicted**
- **M — Mythological/cultural**
- **S — Speculative/inspirational**

## Independence rule

Three videos repeating the same book, website, photograph or archaeological claim count as **one source lineage**, not three independent confirmations. Independent corroboration requires a genuinely separate evidentiary chain.

## Computational control

Every model requires assumptions, inputs, parameters, versioned code, baseline/null model, uncertainty/limitations and validation target. AI optimisation follows model verification and validation; it does not replace them.

## Source genealogy record

Each indexed claim should carry:

`Source ID → source type → exact title → creator/author → date → URL/stable ID → page/timestamp → claim → cited lineage → independent sources → evidence status → Biupiu division → CODEX model/commit → experimental path → IP status → NFT relevance`
