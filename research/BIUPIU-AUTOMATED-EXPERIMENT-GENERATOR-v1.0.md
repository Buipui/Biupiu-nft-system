# Biupiu Automated Experiment Generator v1.0

## Input
A sourced claim, research question, hypothesis or validated computational finding.

## Output structure
`SOURCE → CLAIM → HYPOTHESIS → PREDICTION → VARIABLES → CONTROLS → EQUIPMENT → METHOD → MEASUREMENTS → EXPECTED OUTCOME → FAILURE CONDITIONS → SAFETY GATES → ANALYSIS → REPLICATION`

The generator must expose assumptions, uncertainty and missing equipment/data. It must never describe a proposed test as completed.

## Integration targets
Experimental Control Centre; CODEX; Virtual Laboratory; Materials Genome; Failure Register; Knowledge Graph; IP Firewall; Prototype Queue.
