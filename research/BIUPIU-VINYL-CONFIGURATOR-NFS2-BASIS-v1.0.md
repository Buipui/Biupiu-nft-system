# Biupiu Vinyl / PPF Configurator — NFS-II Baseline v1.0

**Status:** IMPLEMENTED — configuration architecture

## Design basis
NFS II is the historical simplicity reference: first choose a predefined factory colour swatch. Later NFS systems demonstrate the progression toward custom colour, finish controls and vinyl/livery layers. Biupiu extends this into a real material configurator.
## Layer model
1. Base substrate/body material
2. Base colour swatch
3. Vinyl/PPF film
4. Pattern/livery
5. Secondary accent
6. Finish
7. Material response
8. Interior/textile coordination
9. Provenance/material data
10. Save/share/export
## Vinyl object
BPU-CMP-COAT-001 — Biupiu sustainable vinyl/PPF surface system.
## Supporting objects
BPU-COL-#### colour; BPU-MATCOL-#### material-colour pairing; BPU-CMP-MAT-001 HempCarbon structural composite panel; BPU-ALG-COL-001 colour configuration engine.
## Pattern engine
repeat/tiling; scale; rotation; mirror; layer order; opacity; masking; edge bleed; component surface assignment; computational-geometry pattern ID.
## Export
configuration ID; colour IDs; material IDs; finish IDs; vinyl/PPF ID; pattern ID; render parameters; provenance; evidence state; compatible product/component IDs.
