## Earliest anthropology-specific retrieval pattern located
Yale's Institute of Human Relations began designing the Cross-Cultural Survey in 1935 specifically to enable rapid retrieval of information across a broad range of societies. HRAF subsequently formalized this into a structured corpus using original source text, systematic subject classification, human subject indexing at paragraph/sentence level, centralized collection and culture-level organization.

This is adopted as a historical research/search architecture reference, not copied data.

## Historical search layers harvested
### 1. Pre-computer anthropological retrieval
- original source preservation
- physical filing/index cards/slips
- culture as an organizing key
- subject classification
- human-curated indexing
- source context retained

### 2. HRAF / Cross-Cultural Survey pattern
- rapid cross-cultural retrieval
- Outline of Cultural Materials (OCM) subject categories
- paragraph-level indexing
- culture-level grouping
- comparable metadata
- source text retained for researcher evaluation
- later electronic transformation without abandoning archival structure

### 3. Bibliographic anthropology indexing
Anthropological Index / Anthropological Index Online and Harvard's Anthropological Literature provide a long-running bibliographic layer spanning anthropology and related fields. Their combined continuation is represented today by Anthropology Plus.

### 4. Full-text / digital anthropology
AnthroSource supplies searchable AAA publications. eHRAF provides paragraph-level anthropological subject indexing, culture/region filtering, thesaurus-assisted search and expert search syntax.

### 5. Modern federated retrieval
Current systems add lexical, semantic, metadata, hybrid and API/service-oriented retrieval. These are integrated only after provenance and evidence checks.

## Context-preservation rule
Search results must preserve enough context to prevent decontextualized interpretation:
source → author/collector → date → culture/site/population → document → passage/paragraph → subject code → interpretation/evidence state.

## Evidence rule
Anthropological material is not automatically factual merely because it is old, indexed or widely cited. Colonial-era descriptions, secondary interpretations, speculative archaeology and community traditions require their own evidence classification and attribution.

## Biupiu evidence classes
DOCUMENTED — directly supported by reliable source evidence.
RECONSTRUCTED — computational/physical reconstruction from documented evidence.
EXPERIMENTAL — Biupiu test of a model.
HYPOTHESIS — proposed interpretation requiring verification.
SPECULATIVE — exploratory/creative research.
REJECTED — contradicted, unsafe, unverifiable or otherwise unsuitable.
