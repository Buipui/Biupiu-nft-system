## Selection rule

P1/P2 resources become formal Biupiu architecture references. Candidate resources require licence, compatibility, maintenance and security review before production adoption.

## Provenance

All upstream resources must retain their original attribution and repository URL in downstream documentation. No assumption of commercial redistribution rights is made from GitHub availability alone.
