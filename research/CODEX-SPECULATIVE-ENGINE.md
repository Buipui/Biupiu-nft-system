# BIUPIU CODEX — Speculative Research & Cartographic Testing Engine

**Version:** 1.0  
**Date:** 15 September 2026  
**Status:** Architecture indexed; implementation roadmap established

## Purpose

Convert speculative claims from Vibes of Cosmos, Robert Sepehr / Atlantean Gardens, Divergent Libertalia and related sources into explicit, reproducible, testable research problems.

> Take the hypothesis seriously enough to test it, but not seriously enough to assume it is true.

## Evidence hierarchy

A — Directly demonstrated  
B — Strongly supported  
C — Plausible/incomplete  
D — Testable hypothesis  
E — Unsupported/contradicted  
M — Mythological/cultural

Creator ≠ source ≠ original evidence. Repeated claims are not independent corroboration.

## Pipeline

`video/map → exact claim → timestamp/source → source genealogy → measurable prediction → GIS/geometry → null hypothesis → authoritative dataset → statistical/physical test → uncertainty → evidence status → research record`

## CODEX modules

### CODEX-SPEC-GIS
Claim-to-coordinate conversion; map feature extraction; GIS layers; uncertainty metadata.

### CODEX-CARTOFORENSICS
Projection identification, georeferencing, scale analysis, historical-map comparison, coordinate transformation and positional-error tracking.

### CODEX-MOONMAP
Reconstruct proposed lunar-image-to-world-map transformations; quantify projection distortion and compare outputs with modern geodetic baselines.

### CODEX-BATHY
Compare proposed hidden-land/underwater features with bathymetry, gravity, geology and palaeogeographic datasets.

### CODEX-ANTARCTICA
Compare Terra Vista, lands-beyond-Antarctica and ice-wall hypotheses against Antarctic topography, bathymetry, satellite and geological observations.

### CODEX-PALAEO
Reconstruct coastlines, rivers, lakes, ice sheets and exposed continental shelves through time.

### CODEX-VIS
Historical-image provenance, geolocation, architectural analysis and anomaly classification.

### CODEX-SOURCEGRAPH
Build a directed graph from original source → later publication → creator → derivative claim. Detect copied claims masquerading as independent corroboration.

### CODEX-HCI — Hypothesis Convergence Index
Measure convergence only after source independence has been established. Multiple channels repeating one source do not increase independent evidence.

### CODEX-SPS — Speculative Priority Score
Prioritise claims according to testability, evidence potential, geographic specificity, reproducibility and relevance to Biupiu research—not popularity.

### CODEX-ALIGN
Monte Carlo/statistical testing of sacred-site, astronomical, magnetic, geological and proposed ley-line alignments. Ley lines remain an unproven hypothesis.

### CODEX-RESET
Before/after landscape reconstruction for earthquakes, tsunamis, floods, volcanoes, landslides, sea-level change and other documented events. No assumption of a single global reset.

### CODEX-UNDERGROUND
GIS/connectivity analysis of documented caves, tunnels, temples and subterranean structures. Remote-sensing anomalies are not automatically tunnels.

### CODEX-EPOCH
Convert proposed cosmic/chronological cycles into mathematical variables and compare with astronomical, palaeoclimate and archaeological datasets.

## Standard test record

Every CODEX speculative test should contain:

- Test ID
- Source ID
- Exact claim
- Source timestamp/page
- Earliest identifiable source
- Source-independence status
- Geographic proposition
- Chronological proposition
- Physical prediction
- Null hypothesis
- Alternative hypothesis
- Dataset(s)
- Coordinate reference system
- Model/algorithm
- Parameters
- Uncertainty
- Result
- Reproducibility information
- Evidence status
- Negative-result record
- Follow-up experiment
- IP/licensing status

## Core analytical rule

A speculative map is not evidence that the mapped geography exists. It becomes scientifically useful when it produces a falsifiable prediction that can be compared with independent observations.

## IP controls

Third-party maps, videos, photographs, code and datasets remain subject to their licences. Do not reproduce copyrighted maps as Biupiu artwork without permission. Prefer original Biupiu-generated analytical layers, measurements and models. Keep potentially patentable or confidential Biupiu implementations separate from public source analysis.

## Integration
