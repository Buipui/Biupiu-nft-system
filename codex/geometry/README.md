# Biupiu CODEX — Complex Geometry

This directory is the executable geometry layer corresponding to
`research/BIUPIU-COMPLEX-GEOMETRY-THUNDERBOLTS-CODEX-v1.0.md`.

## Implemented primitives

- torus
- stacked torus
- helix / spiral
- nested spiral families
- hourglass profile
- nested harmonic waves
- vortex-ring centreline

## Research boundary

These are mathematical primitives. Their use does not establish any physical,
plasma, electromagnetic, cosmological or archaeological interpretation attached
to source material. Physical models require their own equations, units,
boundary conditions, numerical validation and experimental evidence.

## Reproducibility

Geometry generation is deterministic for identical parameters. Future NFT
artwork generation must record algorithm version, parameters, seed where used,
dependencies and output hashes.
