# Biupiu Digital Laboratory v1.0

## Purpose
A reproducible, evidence-controlled environment for evaluating speculative claims from the Biupiu research portfolio. The lab distinguishes:

- **Supported:** results reproduce under stated assumptions and agree with established theory or reference data.
- **Inconclusive:** simulation or data is insufficient to decide.
- **Refuted under test conditions:** the claim fails the predefined test.
- **Not tested:** protocol exists but execution has not yet completed.

## Rules
1. Every experiment must state a falsifiable claim, assumptions, variables, baseline, metric, and stopping criteria.
2. Simulations do not prove real-world performance; they only test the model used.
3. Extraordinary claims require independent replication, sensitivity analysis, and preferably physical measurements.
4. No result is upgraded to a confirmed engineering fact without external validation.
5. All results must include code version, random seed, parameters, and limitations.
