# Biupiu Asset Studio UE5 Project

This is the source-controlled Unreal Engine project scaffold for Biupiu's 3D asset workflow.

The Unreal Engine installation itself remains external to Git. Generated folders and engine binaries must not be committed.

## First asset test

Import a mesh into /Game/Biupiu/Assets/Geometry, create or assign a material under /Game/Biupiu/Assets/Materials, place the asset in the startup map, save, and run the visual validation gate.
