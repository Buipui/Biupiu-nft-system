# Biupiu Trust / Blockchain Roadmap

## T-01 Trust foundation — specified
- Architecture
- Canonical records
- Hash-linked audit events
- Verification model
- Off-chain/on-chain separation

## T-02 Executable integrity layer
- Canonical serializer
- SHA-256 hashing
- Append-only event ledger
- Verification tests
- Sequence/replay protection

## T-03 Key and authorization layer
- Signature abstraction
- Key rotation/revocation
- Multi-party approval
- Security tests

## T-04 Blockchain adapter
- Generic chain adapter
- Testnet anchoring
- Anchor verification
- Retry/recovery handling

## T-05 Biupiu-native chain research
- Network requirements
- Permissioned vs permissionless analysis
- Transaction/state model
- Consensus research
- Local multi-node simulation

A Biupiu-native blockchain is not considered implemented until a reproducible multi-node test demonstrates agreement, validation and recovery.
