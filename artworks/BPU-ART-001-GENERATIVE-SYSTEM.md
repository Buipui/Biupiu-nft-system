## 1. Purpose

Define a reproducible computational-art system for the first Biupiu Genesis artwork. The system separates artistic parameters from source artwork files so that future editions can be regenerated, audited and compared without claiming that an output is historically authentic or scientifically validated.

## 2. Geometry Model

The initial system uses a parameterized radial construction:

1. Establish a normalized centre point `(0,0)`.
2. Select a radial division count `N`.
3. Generate equally spaced angular positions `theta_i = 2πi/N`.
4. Construct one or more concentric radius layers.
5. Apply controlled repetition, rotation and scale transformations.
6. Connect selected points or transformed copies according to the chosen pattern rule.
7. Add optional secondary geometry such as arcs, polygons or nested radial grids.
8. Render the resulting geometry as a deterministic artwork layer.

This is a creative construction model, not a claim about the construction method of any ancient culture.

## 4. Reproducibility Standard

Every finalized artwork generation should preserve:

- generation date/time;
- software/tool version;
- parameter set;
- random seed where applicable;
- source code or procedural description;
- source-file hash;
- final-render hash;
- output dimensions and format.

If a parameter changes, the artwork receives a new revision rather than silently replacing the previous state.

## 5. Research Linkage

The system may be informed by research into mathematical patterns, historical architecture, ancient engineering and material culture. Each specific historical influence must be documented in `research/` with an identifiable source before being described as a research finding.

## 6. Artwork Layers

**Layer A — Primary Geometry:** radial construction and proportional framework.  
**Layer B — Repetition:** controlled geometric duplication and rotation.  
**Layer C — Secondary Pattern:** nested or intersecting structures.  
**Layer D — Material/Visual Treatment:** final aesthetic treatment selected during production.  
**Layer E — Provenance Overlay:** optional non-artistic record information retained separately from the master artwork.

## 7. Production Workflow

**Phase 1 — Construct:** generate the base geometry.  
**Phase 2 — Explore:** produce controlled parameter variations.  
**Phase 3 — Select:** identify the canonical Genesis Study output.  
**Phase 4 — Lock:** freeze parameters and record the seed/version.  
**Phase 5 — Archive:** preserve source, render and hashes.  
**Phase 6 — Metadata:** update BPU-NFT-2026-001.  
**Phase 7 — Review:** complete provenance/IP/release checks before any mint.

## 8. Edition Logic

The canonical artwork should be distinguishable from derivative parameter studies. Variants may change one controlled variable at a time and receive separate internal identifiers before any public edition is considered.
