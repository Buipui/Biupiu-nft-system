This matrix defines the first controlled exploration set for Genesis Geometry Study 001.

| Variant | Change | Purpose | Status |
|---|---|---|---|
| G001-A | Baseline radial geometry | Reference construction | Planned |
| G001-B | Increase radial divisions | Test pattern density | Planned |
| G001-C | Reduce concentric layers | Test visual simplicity | Planned |

## Rule

Only one primary parameter should change between controlled variants unless a new experimental branch is explicitly documented. The canonical artwork will be selected after visual review and provenance checks.

## Record Requirement

Each rendered variant should receive a unique filename, parameter record and hash. No variant should be marketed or minted merely because it appears in the development archive.
