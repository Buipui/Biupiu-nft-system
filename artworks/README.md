# Artwork Archive

Use this directory for artwork records, provenance references, certificates and links to the corresponding NFT metadata.

## Provenance Master Reference

- `provenance/BIUPIU-NFT-PROVENANCE-ARTPIECE-MASTER-REFERENCE-v1.0.md` — canonical master reference for the **01_PROVENANCE** art-piece standard, based on BIU-NFT-0001 — Ancient Water / Computational Flow I. It defines the visual language, documentary layout, research/algorithm metadata, provenance chain, two-image standard, evidence controls, licensing/IP separation and future-generation guidance.

The provenance master reference is a reusable Copilot/reference standard for future Biupiu NFT provenance art pieces. Future revisions must be versioned rather than silently replacing the historical standard.

## Archive Rule

The provenance art piece is the BIUPIU-branded documentary/certificate layer. The standalone art piece remains an independent collector-facing artwork. The two may share a Research ID / Release ID while retaining separate artwork/file identities and hashes.

Do not place private wallet keys, passwords, seed phrases or other secrets in this repository.
