## 1. PURPOSE AND COPILOT REFERENCE RULE

This document is a standalone master reference for the **01_PROVENANCE** side of the Biupiu two-image NFT standard.

It defines the visual language, information architecture, metadata presentation, provenance logic, computational-art description standard and generation principles demonstrated by the reference artwork **BIU-NFT-0001 — Ancient Water / Computational Flow I**.

### Copilot instruction

For future Biupiu NFT creation, use this document as the baseline reference for the provenance art piece unless a later approved version supersedes it.

The provenance art piece is the **BIUPIU-branded documentary/certificate layer**. It is not the same object as the independent collector-facing standalone artwork.

Future releases should preserve the distinction:

**01_PROVENANCE = research identity + provenance + technical record + authenticity/documentation layer**  
**02_STANDALONE = independent collector-facing computational artwork**

The two images may share the same research/release record, but each receives its own file/version/hash where applicable.

## 8. SYMMETRY AND RECURSION

Symmetry is a primary design characteristic.

The reference combines strong bilateral/vertical symmetry with radial organization around the central origin.

Recursive visual relationships occur when smaller forms echo larger forms at different scales.

Future generation systems should treat symmetry and recursion as explicit parameters rather than merely decorative effects.

Suggested parameter families:

- `SYMMETRY_MODE`
- `RADIAL_DIVISIONS`
- `AXIS_ROTATION`
- `RECURSION_DEPTH`
- `SCALE_RATIO`
- `NESTING_LEVEL`
- `FORM_REPLICATION`

Do not describe an output as mathematically fractal unless the implemented system actually satisfies an appropriate mathematical definition.

## 21. TWO-IMAGE STANDARD

The Biupiu NFT system uses a paired-artwork concept.

### 01_PROVENANCE

The documentary piece contains:

- Biupiu branding;
- research identity;
- technical metadata;
- algorithm information;
- provenance;
- file/hash information;
- licence/IP statement;
- edition/release status;
- repository or canonical record link;
- research taxonomy.

### 02_STANDALONE

The standalone piece is the independent collector-facing artwork.

It should not be overloaded with technical documentation. Its visual identity should remain connected to the research and algorithm but function as an artwork in its own right.

The pair should share the appropriate Research ID / Release ID while maintaining separate artwork/file identities and hashes.

## 22. EVIDENCE AND CLAIM CONTROL

Biupiu provenance artwork may visually interpret historical, archaeological, biological, engineering or scientific subjects.

Use the repository evidence classifications consistently:

- **DOCUMENTED** — supported by reliable historical, archaeological or scientific evidence.
- **RECONSTRUCTED** — computational/physical reconstruction based on available evidence.
- **EXPERIMENTAL** — Biupiu experiment testing a proposed mechanism/model.
- **HYPOTHESIS** — proposed interpretation requiring further investigation.
- **SPECULATIVE** — creative exploration inspired by a subject.

Artistic resemblance must not be presented as proof.

A computational visualization must not automatically be described as a scientifically validated simulation.

Historical inspiration must not automatically be described as an authentic historical reconstruction.
