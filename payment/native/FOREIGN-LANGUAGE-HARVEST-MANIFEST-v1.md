# Foreign-Language / OEM / Open-Source Harvest Manifest v1

Purpose: controlled harvesting of public, lawful technical material for Biupiu payment and backend security.

Languages: Japanese, Korean, Simplified Chinese, Traditional Chinese, German, French, Spanish, Russian and English cross-validation.

Priority:
1. Official Android/Google Play documentation.
2. OWASP mobile-security guidance.
3. Established open-source billing/subscription systems.
4. OpenZeppelin and established Web3 security references.
5. Public academic/OpenBook material.
6. Public OEM SDKs, developer documentation, security specifications and published interfaces.

OEM boundary:
- Allowed: public SDKs, APIs, developer documentation, published firmware interfaces and security specifications.
- Excluded: proprietary firmware dumps, leaked credentials/keys, DRM bypass material, restricted internal documentation and unlawfully obtained dumps.

Every harvested resource must record URL, language, licence/status, capability, security relevance, compatibility, provenance and cross-validation status.

Foreign-language material is reference evidence, not automatically trusted code. Integration requires licence, dependency, security and test gates.
